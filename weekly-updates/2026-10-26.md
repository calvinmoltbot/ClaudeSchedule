# Claude Desktop & Claude Code Weekly Update
**Week of October 19–26, 2026**

---

## New Features Shipped

### Claude Desktop / Claude App

- **Chat + Cowork unified for Enterprise (Oct 23):** The merged Chat/Cowork experience (launched broadly on Sep 16) reached Enterprise plans on October 23, with admin controls and a new **Efficient mode** for high-volume teams.
- **Cloud tasks:** Tasks that don't require local files now keep running in the cloud after you close your laptop. Scheduled tasks follow the same rule. Tasks started on desktop can be steered from the mobile app.
- **Memory controls:** Users can now click any memory entry to edit or delete it, search past chats, and generate memories from chat history.
- **Claude Duet (research preview, Oct 21):** Opened by waitlist for US Pro and Max subscribers — an experimental multi-model collaboration feature.

### Claude Code CLI

- **Subagents fork by default (v2.1.302, Oct 16):** Forked subagents now share the parent's prompt cache, reducing token costs and latency on multi-agent workflows.
- **`onFailure: "block"` for hooks (around Oct 20):** `PreToolUse` and `PermissionRequest` hooks can now block a tool call when the hook command fails to start, times out, or exits unexpectedly — closing a sandbox escape vector.
- **Auto-mode classifier moved server-side (Oct 19):** The classifier that picks between fast and extended thinking now runs server-side, improving consistency across clients.
- **Security patch wave (Oct 25 week, v2.1.303–2.1.310):** Eight releases this week, most focused on security. v2.1.309 contains 10+ fixes for sandbox and permission-check bypass routes. v2.1.310 patches a hook bypass when Git Bash is missing.

### Models & Platform

- **Claude Haiku 5.5 (Oct 7):** The new fastest/smallest model in the 5.5 family, optimised for summarisation, subagents, and browser use.
- **Opus 5.5 Fast Mode GA (Oct 15):** Generally available, including on Azure (Microsoft Foundry) and Google Cloud.
- **Between-tools thinking metadata:** The Models API now exposes thinking metadata between tool calls for Opus 5.5.
- **Claude Design GA (Oct 8):** Visual design/prototype canvas moved from research preview to generally available on all plans, including Free.

---

## Announced but Not Yet Released

- **Claude Duet:** Still in research preview / waitlist as of Oct 21. No general availability date announced.
- **Motion (beta):** Announced in beta on Oct 8; initial availability limited to Team and Enterprise plans, broader rollout not yet dated.
- **Dashboards (beta):** Also announced Oct 8 in beta alongside Motion.

---

## Community Buzz & Interesting Use Cases

- **Non-dev document pipelines:** A popular Substack post this week demonstrated pointing Claude Code at a data folder and getting a spreadsheet, Word summary, and slide deck from a single prompt — no coding required.
- **Business-team CLAUDE.md workflows:** Marketing, ops, and finance teams are sharing setups where a `CLAUDE.md` keeps generated copy on-brand and campaign metrics auto-converted to HTML dashboards.
- **Security patch momentum:** The 8-release week (v2.1.303–2.1.310) got significant attention from the security community, with several researchers noting the sandbox hardening as a meaningful improvement for enterprise deployments.
- **Subagent fork cost savings:** Early users of v2.1.302's fork-by-default are reporting noticeably lower costs on large multi-agent runs thanks to shared prompt cache.
