# Claude Desktop & Claude Code: Weekly Update
**Week of October 6 – October 12, 2026**

---

## New Features Shipped

### Claude Code

- **Agent tool `effort` parameter** (Oct 6): The `Agent` tool now accepts an `effort` parameter, letting you dial reasoning depth per-agent call without changing your global model settings.
- **`claude plugin install --marketplace`** (Oct 6): The `claude plugin install` command gains a `--marketplace` flag for directly browsing and installing plugins from the official marketplace without leaving the terminal.
- **Subagent auto-compact**: A new setting allows subagents to auto-compact their context window earlier than the main conversation, reducing memory pressure in deeply nested multi-agent workflows.
- **Workflow model override env var**: A new environment variable lets you force every agent spawned by a workflow to use the same model, simplifying cost control for large orchestrations.
- **Larger Read support**: The `Read` tool's size limits have been raised, allowing single-call reads of larger files before truncation kicks in.
- **Claude Code 2.1.296**: The latest release includes fullscreen link underlining and faster transcript toggling, plus bundled as version 2.1.295 inside Claude Desktop (as of Oct 9).
- **Managed-config key deprecation complete** (Oct 7): Older managed-configuration key spellings are no longer accepted. Any configs using pre-deprecation key names must be updated.

### Claude Desktop / Claude.ai

- **Dashboards (beta)** (Oct 8): Anthropic launched a business-data dashboards feature in beta, initially available on Team and Enterprise plans. Dashboards connect to integrated data sources and render live summaries inside the Claude interface.
- **Motion (beta)** (Oct 8): Alongside Dashboards, Anthropic launched Motion — a tool for generating animated explainer content. Also gated to Team and Enterprise initially.
- **Google Workspace integration (public beta)**: Claude now works directly inside Google Docs, Sheets, and Slides via an official add-on. Users can create, edit, and summarize files from within Google apps or drive actions from Claude.
- **Cowork cloud migration live** (Oct 6): As announced, new Cowork tasks on Pro and Max plans now run in the cloud. The local-only Cowork option has been removed for these tiers.

### Claude Platform / API

- **Browser and computer-use SDK classes (beta)** (Oct 7): Anthropic added beta browser and computer-use tool classes to the official Python and TypeScript SDKs, making it easier to integrate GUI automation into Claude-powered agents.

## Announced but Not Yet Released

- **Agentic Claude at Global AI Summit**: Anthropic's upcoming model capable of multi-step, objective-driven tasks with minimal human oversight is expected to be the centerpiece of a Global AI Summit demonstration scheduled for late October 2026.
- **New Claude model**: Anthropic is reportedly evaluating a new model positioned to compete with OpenAI's GPT-6 Astra. No timeline confirmed.
- **Usage policy update** (effective Nov 12): A rewrite of Anthropic's usage policies was announced this week. Headline changes include a ban on sustained and needless abusive behavior toward Claude models, and updated rules around weapons software, surveillance tooling, and election targeting content.
- **Anthropic IPO**: Widely reported plans to go public in November 2026 at an estimated ~$2 trillion valuation continue to circulate.

## Community Buzz & Interesting Use Cases

- **Mods ecosystem maturation**: Now two weeks after the mods launch, community developers are publishing increasingly sophisticated mods — automatic secret redaction, custom review UIs, and embedded diagnostic panels are among the most-shared examples this week.
- **Dashboards beta excitement**: The Dashboards launch generated significant discussion among enterprise users who have been waiting for native data connectivity. Early testers report it works well with connected Notion and Google Workspace sources; broader connector support is requested.
- **Google Workspace integration adoption**: The Workspace add-on is seeing rapid early uptake, with productivity-focused creators posting workflow demos showing Claude drafting reports in Docs, cleaning data in Sheets, and generating slide outlines in Slides without leaving those apps.
- **Cowork cloud backlash continues**: Privacy-conscious developers and teams in regulated industries are pushing back on the removal of local-only Cowork mode. Discussion threads on the r/ClaudeCode subreddit are the most active they've been since the Mods launch.
- **Claude for Startups pause**: Anthropic's expanded startup offer — a free year of Claude Team plus $1,000 in API credits — launched October 6 and was paused within days after applications overwhelmed intake. Many founders shared their disappointment publicly; Anthropic has not given a reopening timeline.
- **Federal science deal reaction**: Anthropic's $150 million, three-year commitment to give 15+ US federal science agencies access to Claude (announced Oct 8 as the "Genesis Mission" contract) generated broad media coverage and debate about AI in government research.
