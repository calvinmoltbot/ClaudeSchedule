# Claude Weekly Update — May 4, 2026

_Covering: April 27–May 4, 2026_

---

## Shipped This Week

### /ultrareview — Public Research Preview
A fleet of cloud-hosted bug-hunting agents that scan your codebase in parallel. Findings stream back automatically into your CLI session or the Desktop app. Available as a public research preview for Pro, Max, Team, and Enterprise users.

### Session Recap
When you return to a terminal that was unfocused, a compact recap shows exactly what Claude did while you were away — tool calls made, files changed, decisions taken — so you can pick up without scrolling.

### Custom Themes
Build and distribute color palettes for the Claude Code interface via the new `/theme` command or a plugin. Theme packages can be shared and installed like any other plugin.

### Claude Code Web Redesign
The Claude Code web interface gets a sessions sidebar and drag-and-drop layout, matching the multi-session desktop experience shipped in the April 14 redesign. Available to all Claude Code on the web users.

### Three Interface View Modes
A new mode toggle lets you dial verbosity: **Verbose** shows every tool call in full; **Normal** shows balanced output; **Summary** shows only results. Keyboard shortcuts added for session switching, spawning, and navigation. A usage button now displays both context-window and session usage at a glance.

### Opus 4.7 Now Default on Max and Team Premium
Claude Opus 4.7 replaces the previous default for Max and Team Premium subscribers. The interactive `/effort` slider makes it easy to dial between effort levels; `xhigh` is now the recommended setting for most coding work.

### Windows: PowerShell Fallback
Git for Windows (Git Bash) is no longer a hard requirement on Windows. When absent, Claude Code automatically falls back to PowerShell as the shell tool.

### CLI Quality-of-Life Additions
- `${CLAUDE_EFFORT}` is now available as a variable in skill content, letting skills adapt to the active effort level.
- The `/model` picker now fetches model lists from your gateway's `/v1/models` endpoint when `ANTHROPIC_BASE_URL` points at an Anthropic-compatible gateway.
- `claude project purge [path]` deletes all Claude Code state for a project (transcripts, tasks, file history, config entry). Flags: `--dry-run`, `-y/--yes`, `-i/--interactive`, `--all`.
- PostToolUse hooks can now replace tool output for **all** tools via `hookSpecificOutput.updatedToolOutput` (previously MCP-only).
- MCP servers that hit a transient startup error now auto-retry up to 3 times instead of staying disconnected.

**Version 2.1.126** released May 1, 2026.

## Community Buzz

**Prompt injection fallout lingers.** A leaked source code dump in late April revealed a prompt injection vulnerability in Claude Code. Anthropic patched it quickly, but the incident fueled ongoing discussion about agentic security hygiene. The leaked code also surfaced internal model codenames (Sonnet 4.8, Mythos, Numbat, KAIROS), giving the community an unexpected peek at the roadmap.

**Six-week regression retrospective.** A detailed GitHub Gist tracing every Claude Code regression from early March through late April is making the rounds, with developers cross-referencing it against their own timelines. The takeaway: the April 14 desktop redesign resolved most issues, but token burn on the new multi-session layout remains a concern.

**Codex vs Claude Code, round two.** With Claude Code gaining Windows parity and shipping computer use, comparison threads are back. A popular Softr blog post and several X threads conclude that Claude Code's agentic depth now outpaces Codex for complex codebase work, while Codex retains an edge for quick edits in existing IDEs.

**Computer Use for business automation.** MindStudio published eight real-world business use cases for Claude Code computer use — LinkedIn outreach, ad management, form filling, and similar repetitive UI tasks — driving a wave of "I didn't know it could do that" posts from non-developer users.
