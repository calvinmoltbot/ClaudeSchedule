# Claude Weekly Update — August 17, 2026

> Covering Claude Desktop and Claude Code updates from the past 7 days.

---

## Claude Code — Shipped

### Auto Mode Now Default (August 14)
Auto mode is now the default permission mode for new sessions on **Pro, Max, and Team plans**. Previously users had to opt in; new sessions now start in auto mode out of the box.

### Version 2.1.233 Highlights (August 14)
- **GitLab merge request URL support** added to the `--worktree` flag and `claude agents` view.
- **Opt-in `forward_user_identity`** apps gateway setting for Anthropic upstreams.
- **Memory cgroup support** for Bash tool commands on Linux (opt-in).

### Cross-Session Messaging
Sessions can now **message each other across machines** via `SendMessage` with `ListAgents` for discovery — available on macOS and Linux. Useful for multi-agent workflows spanning different local sessions.

### Self-Hosted Environments (Public Beta — Team & Enterprise)
`claude self-hosted-runner` lets you turn your own machines or containers into execution environments for Claude Code web, mobile, and desktop sessions. Now in public beta on Team and Enterprise plans.

### Archive Plugin Source
Sessions can install plugins from a **zip over HTTPS** (no git or npm required), with optional SHA-256 pinning for integrity verification.

### VSCode Focus View
New Focus view in the VS Code sidebar with:
- Better sandbox credential masking
- Stronger plugin, MCP, and permission handling
- Session grouping in the sidebar
- Smoother streaming with improved keepalive handling

### Remote Control Resume
Remote Control now supports resuming sessions, along with richer plugin marketplace command sources.

## Claude Desktop — Shipped

### Monthly Recap & Focus Settings (Beta)
**Settings > Reflect** now shows:
- Topics you've spent time on
- Most active day and peak hour
- Observations about how you work with Claude

**Settings > Time and Focus** adds optional break reminders and quiet hours. Available in beta on Free, Pro, and Max plans (web + Desktop). Requires memory to be enabled.

### Cowork Expansion
**Claude Cowork** is rolling out beyond desktop — now available on web and mobile too, starting with the Max plan. Computer use in Cowork works directly through the desktop app or via remote web/mobile sessions with no extra setup.

### Skill & Plugin Security Scanning (Beta — Enterprise)
New automated security scanning for third-party skills and plugins uploaded or edited on Enterprise plans. Checks for malicious content at upload/edit time.

## Claude Platform — Notable Changes

### Sonnet 5 Standard Pricing (August 10)
Claude Sonnet 5 transitioned from introductory to **standard pricing** on August 10.

### Legacy Workbench Sunset (August 17)
The legacy Workbench in the Claude Console was retired today. The experimental prompt tools APIs (generate, improve, templatize prompts) were also retired alongside it.

### Opus 4.1 Deprecation
Claude Opus 4.1 was retired (August 5 deadline). Anthropic recommends migrating to **Claude Opus 4.8**.

### Claude Tag in Slack
Smarter Slack integration: Claude Tag now uses full channel context, memory, and standing instructions to decide when to respond proactively — at no extra cost on supported plans.

### Claude for Government (Beta)
Anthropic launched **Claude for Government** in beta in August 2026, with Anthropic remaining the contracted and billing party for government agencies.
