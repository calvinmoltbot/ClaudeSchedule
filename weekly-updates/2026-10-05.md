# Claude Desktop & Claude Code: Weekly Update
**Week of September 29 – October 5, 2026**

---

## New Features Shipped

### Claude Code

- **Claude Mods** (launched October 1): The headline feature of the week. Claude Code now supports *mods* — small, event-driven TypeScript/JavaScript functions that hook into internal events and can alter behavior in real time. Mods can:
  - Block, rewrite, or retry a tool call before it executes
  - Approve or deny a permission request programmatically
  - Redact secrets from tool output before Claude reads it
  - Edit or replace parts of the Claude Code interface (tool results, questions, buttons, inputs)
  - Other mods can respond to button presses from your mods
  Mods ship inside plugins, can be shared through the plugin directory, and give teams fine-grained control over Claude Code's behavior.
- **Built-in "You Should Know" mod**: A built-in mod where a side agent watches your session and flags things you or Claude might miss. Enable with `/plugin enable cc-plugin-you-should-know@builtin`.
- **`--desktop` CLI flag** (v2.1.285): `claude --desktop` opens the Claude Desktop app on the current directory. Use `--continue` or `--resume <id>` to open a specific session directly.
- **`claude agents` CLI command**: Lists all agents configured for the current session.
- **Ctrl+C draft recovery**: Pressing Up on an empty prompt now restores a draft cleared by Ctrl+C, including pasted text and images.
- **Claude Code 2.1.288 stability release**: Broad reliability and UX improvements — smarter resume and recovery flows, stronger plugin and MCP handling, improved permission and auto mode behavior.

### Claude Desktop / Claude.ai

- **Cowork cloud migration** (effective October 6): New Cowork tasks on Pro and Max plans now run in the cloud by default; the option to run tasks only on your local computer is being removed.
- The broader unified Claude experience rollout (announced last week) is continuing its gradual expansion to Pro and Max users on web, desktop, and mobile.

### Plugin Ecosystem

- Over **14,000 community plugins** now indexed in community registries, on top of Anthropic's official 101-plugin marketplace (33 first-party, 68 partner integrations).
- The mods launch unlocked a new category of plugins focused on interface and behavior customization rather than just external tool connections.

## Community Buzz & Interesting Use Cases

- **Mods adoption sprint**: Developers who got early access to mods built working games and context monitors within days of launch, highlighting the low barrier to authoring custom behavior.
- **Games inside Claude Code**: Several examples of mini-games embedded in the Claude Code interface (using mod-powered UI hooks) circulated on the r/ClaudeCode subreddit and Hacker News.
- **Security-focused mods**: Community members are building mods that auto-redact API keys and tokens from tool output, a pain point many teams have had since Claude Code's early days.
- **Plugin ecosystem maturity**: With 14,000+ community plugins indexed, developers are publishing "starter packs" — curated plugin bundles for specific workflows (frontend dev, data science, DevOps) to make onboarding easier.
- **Cowork cloud shift discussion**: The removal of local-only Cowork mode is generating debate — privacy-conscious users are pushing back, while enterprise users welcome the reliability improvement.
