# Claude Weekly Update — September 14, 2026

> Covering Claude Desktop and Claude Code updates from the past 7 days (2026-09-07 to 2026-09-14).

## Claude Code — Shipped

### v2.1.263+ — Bug Fixes and Reliability (September 6–8)
A series of patch releases followed last week's large drop, tightening reliability across CLI, VS Code, web, and Slack:
- Fixed read-only git commands unexpectedly prompting for permission after a session had been running for a while
- Fixed connector timeouts, elevated CPU usage, and feature flag application issues
- Fixed session resumption edge cases

### Plugin Evals + Output Styles — Broad Feature Release (mid-September)
Anthropic shipped a significant broad release this week combining several features:

**New commands:**
- **`claude plugin eval`** — runs a plugin's eval suite and returns scored, reproducible results in JSON and HTML report format; designed for CI integration and for plugin authors validating their plugins work correctly
- **`/output-style [name]`** — lists and switches output styles (e.g. concise, verbose, custom styles); works over Remote Control and in headless sessions

**Workflow and telemetry controls:**
- Stronger per-workflow controls and improved telemetry pipeline management

### v2.1.270 — Git Permission Fix (this week)
- Fixed a bug where git commands would unexpectedly ask for permission during long-running sessions — a regression that had been frustrating users running extended agentic workloads

### Usage Limits Increase (September 14) ⭐
Starting today, Anthropic **permanently raised standard weekly limits in Claude Code by 25%** for Pro, Max, Team, and seat-based Enterprise plans. The increase is measured against the standard limit that applied before any promotional periods.

## Claude Desktop & Platform — Shipped

### Cowork on Web & Mobile — Remote Sessions (GA Beta)
Cowork computer use, previously desktop-only, is now available on web and mobile through remote sessions (beta). Sessions run server-side — files and state are saved to your Claude account and synced across devices. The key implications:
- **No device needs to stay on** — scheduled tasks run on Anthropic's schedule server
- Session continuity across device switches (start on desktop, resume on mobile)
- Agentic tasks can run overnight without keeping your laptop awake

### Rendering & Performance Improvements
Several rendering fixes shipped for Desktop and web:
- Significantly less re-render work per turn in long conversations
- **Streaming no longer slows down as the reply grows** — a notable quality-of-life fix for long code or document generations
- Background-agent updates no longer trigger a full-screen re-render
- Improved prompt input responsiveness (reduced per-keystroke rendering work)

### Bug Fixes
- Fixed Claude apps gateway incorrectly telling Claude Desktop to export OpenTelemetry as JSON when the terminal CLI uses protobuf — caused Desktop telemetry to be rejected by protobuf-only collectors
- Fixed Desktop and web showing a session as "busy" while it was only watching an artifact for updates (no actual work being done)

### Anthropic Compute Commitments (~$517B)
Reported this week: Anthropic has lined up approximately **$517 billion in compute commitments**. This is a leading indicator for future rate limit increases and potential pricing adjustments. No immediate changes announced, but the scale signals significant infrastructure expansion ahead.

## Security & Trust

### Threat Intelligence Report — AI Misuse (September 2026)
Anthropic published its threat intelligence report "Detecting and countering misuse of AI: September 2026," covering activity disrupted between December 2025 and August 2026. Key findings:
- Seven harm areas monitored: cyber operations, influence operations, surveillance, scams and fraud, **biological misuse**, conventional weapons development, and distillation
- **Five cases identified involving potential bioweapons research** — Claude was used by individuals attempting to support biological weapons development; Anthropic disrupted all five
- The report is positioned as an ongoing transparency effort, with future reports expected quarterly

This is the first time Anthropic has publicly disclosed Claude misuse cases at this level of specificity. Worth reading for anyone thinking about responsible deployment.
