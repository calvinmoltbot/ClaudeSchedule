# Claude Weekly Update — May 18, 2026

> Covering Claude Code and Claude Desktop news from the past 7 days (May 11–18, 2026).

---

## Shipped: New Features & Changes

### Claude Code — Agent View
The headline CLI addition this week is **`claude agents`**, a single unified list of every Claude Code session — running, blocked on you, or done. From one view you can start agents, send them to the background, check status, peek at the last response, and jump back in only when input is needed. Real-time updates land without refreshing.

### Claude Code — Fast Mode Upgrade
**Fast mode now uses Claude Opus 4.7 by default** (previously Opus 4.6). Faster output, same model tier.

### Claude Code — Plugin & Marketplace Improvements
- **Projected context cost** (per-turn and per-invocation token estimates) added to the `/plugin` marketplace browse pane
- Stronger plugin dependency enforcement — missing dependencies are caught earlier and surfaced clearly
- Plugins with a root-level `SKILL.md` and no `skills/` subdirectory are now auto-surfaced as a skill
- `/plugin` details pane now lists any LSP servers the plugin provides

### Claude Code — Background Session Control
New `worktree.bgIsolation: "none"` setting lets background sessions edit the working copy directly without `EnterWorktree`, for repos where Git worktrees are impractical.

### Claude Code — Expanded `claude agents` Flags
New flags for configuring dispatched background sessions:
`--add-dir`, `--settings`, `--mcp-config`, `--plugin-dir`, `--permission-mode`, `--model`, `--effort`, `--dangerously-skip-permissions`

### Claude Code — Rate Limits Doubled
Paid rate limits were doubled for developers, startups, and enterprises to support higher-throughput production workloads.

### Claude Desktop — Hardware Interface (Bluetooth API)
Anthropic opened its **Claude Hardware Interface** (Bluetooth Low Energy API) to developers. The reference implementation is **Claude Desktop Buddy** — an open-source ESP32-S3 desk companion that connects directly to the Claude desktop app over BLE. First official physical hardware integration.

### Claude Opus 4.7 Released
A new model in the Opus 4 family shipped this week. Fast mode in Claude Code defaults to it immediately; it's also the new recommended choice for long-horizon agent tasks.

### Claude for Small Business
Anthropic launched **Claude for Small Business** with pre-built integrations into QuickBooks, PayPal, HubSpot, Canva, Docusign, Google Workspace, and Microsoft 365. Ready-to-run workflows — no setup required beyond auth.

### Claude for Microsoft 365 — Outlook Public Beta
Following last week's GA of Claude for Excel, PowerPoint, and Word, **Outlook support entered public beta** this week.

### Legal Expansion: 20+ New MCP Connectors
Claude shipped **20+ legal MCP connectors** and **12 practice-area plugins** covering research, contracts, discovery, matter management, and legal aid. Targeted at law firms and in-house teams.

### Claude Platform on AWS
The full Claude API feature set is now available under AWS billing and authentication, with no separate Anthropic account required.
