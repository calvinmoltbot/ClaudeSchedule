# Claude Weekly Update — May 11, 2026

> Covering Claude Code and Claude Desktop news from the past 7 days (May 4–11, 2026).

---

## Shipped: New Features & Changes

### Claude Desktop Redesign
The Claude Code desktop app received a significant redesign focused on running more tasks in parallel:
- New **session sidebar** for managing multiple concurrent sessions
- **Drag-and-drop workspace** layout for arranging your environment
- **Integrated terminal and file editor** built directly into the app
- **SSH support on Mac**
- Faster diffs, expanded previews, and broad performance/reliability improvements

### Claude Code CLI Updates
A wide-ranging update shipped to the CLI this week:
- **`claude ultrareview` subcommand** — run `/ultrareview` non-interactively from CI or scripts
- **`--plugin-dir`** now accepts `.zip` plugin archives (not just directories)
- **`--plugin-url`** flag fetches plugin archives from URLs for the current session
- **`CLAUDE_CODE_SESSION_ID`** is now injected into the Bash tool subprocess environment
- **`CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1`** lets you opt out of the fullscreen alternate-screen renderer
- `/color` now picks a random session color when no argument is given
- `/mcp` now shows tool counts for connected servers
- **PowerShell fallback on Windows** for shell compatibility
- MCP server reconnects no longer flood the conversation with full tool-name lists — re-announced tools are summarized by server prefix
- Smarter skills/plugin validation and faster startup

### Claude Managed Agents: Three New Features
Announced at Code with Claude SF (see below), all in preview:
- **Multiagent Orchestration** — spin up a fleet of specialized sub-agents; a lead agent breaks a job into pieces and delegates each to a specialist with its own model, prompt, and tools
- **Outcomes** — write a rubric defining what success looks like; Claude iterates autonomously until it meets the bar
- **Dreaming** — Claude reviews previous sessions to find patterns and self-improve over time (extends persistent memory across runs)

### Claude for Microsoft 365
Claude add-ins now work across **Excel, PowerPoint, and Word**, with **Outlook support coming soon**. Context carries automatically between applications.

## Big News: Anthropic × SpaceX Compute Partnership

Anthropic announced it will use **Colossus 1**, SpaceX's massive Memphis data center, in full. Immediate impact:
- **2× rate limits** for paid Claude Code subscribers
- Removal of peak-hour rate-limit reductions
- "Considerable" increase to Claude Opus API rate limits

This was the headline announcement at **Code with Claude 2026 (San Francisco, May 6)**, Anthropic's developer conference. The event also included a free global livestream.
