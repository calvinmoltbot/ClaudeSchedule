# Claude Weekly Update — July 13, 2026

> Covering Claude Desktop, Claude Code, and Anthropic announcements from the past 7 days.

---

## Shipped This Week

### Claude Cowork Expands to Mobile and Web
The biggest product news this week: Cowork is no longer desktop-only. Sessions and files now follow you across devices — your work continues when you close your laptop, scheduled tasks run without any device online, and mobile approvals let you keep background agents moving from your phone. Rolling out gradually over the next several weeks, starting with Max plan users.

### Claude Desktop Comes to Linux
Anthropic released an official Linux beta for Claude Desktop (Ubuntu and Debian). It ships Chat, Cowork, and Code in a single window — no separate CLI install needed.

### Claude Code: Built-In Browser
Claude Code on desktop now ships with a built-in browser. Claude can pull up docs, designs, or any site, then read, click through, and interact with pages the same way it handles local dev server previews.

### Claude Code: `/doctor` Now Fixes, Not Just Reports
`/doctor` (aliased as `/checkup`) has been upgraded from a read-only diagnostic to an active repair tool — it diagnoses installation issues and then fixes them. It also flags unused skills, MCP servers, and plugins relative to their context cost.

### Claude Code: `/cd` Command
A new `/cd` command lets you move the current session to a different working directory mid-conversation without losing prompt cache state.

### Claude Code: Sub-Agents Can Spawn Sub-Agents
Background agent chains are now allowed up to five levels deep, enabling more autonomous multi-step workflows.

### Claude Code: Artifacts
Session work can now be turned into live, shareable web pages (Artifacts) that update in place — useful for PR walkthroughs, incident pages, dashboards, and checklists.

### Claude Code: Auto Mode on Cloud Providers
Auto mode is now the default on Amazon Bedrock, Google Vertex AI, and Foundry. Bedrock has been updated to Claude Opus 4.8. Auto mode also now blocks destructive git commands when you didn't explicitly request discarding local work.

### Claude Code: Trusted Devices for Remote Control
Admins on Team and Enterprise plans can now require members to verify their device before viewing or steering local Claude Code sessions remotely.

### Claude Code: Agent View Improvements
- Status column now uses full terminal width (was truncating at 64 chars)
- `Ctrl+X` permanently removes a completed session
- Deleted background jobs stay deleted across restarts

### Microsoft 365 Connector: Write Tools Enabled
The M365 connector moved beyond read/search. Claude can now draft, send, and organize email, manage calendar events, update mailbox settings, and create/update files in OneDrive and SharePoint.

### Monthly Recap (`Settings > Reflect`)
A new usage reflection feature shows the topics you spent time on, your most active day and peak hour, and patterns in how you work with Claude. Beta on Free, Pro, and Max plans (web and Desktop). Requires Memory to be on.

## Announced but Not Yet Fully Rolled Out

- **Cowork on mobile/web** — gradual rollout over the next several weeks; not everyone has it yet.
- **Artifacts in Claude Code** — org-only sharing and version history are in beta for Team and Enterprise only.
- **Claude Science** — AI workbench for scientists (computational biology, drug discovery) announced late June; broader access still limited.
- **Dynamic Workflows** — Enterprise/Team/Max research preview; lets Claude Code plan and run hundreds of parallel sub-agents for codebase-scale migrations.

## Community Buzz

**Incident debugging** is a standout emerging use case: engineers kick off an investigation before standup, Claude Code works through logs autonomously, and publishes a shareable Artifact with a timeline, suspect commits, and error-rate chart.

**Startup and small team dev** is a hot topic on Hacker News and Substack. The framing has shifted — Claude Code is increasingly discussed as *infrastructure* rather than a productivity add-on, with developers building full GitHub Actions pipelines around it.

**Computer use** for business automation (LinkedIn outreach, ad management, form filling) is generating practical write-ups. The angle is less "toy demo" and more measurable ROI.

A Hacker News thread on the **May–July 2026 weekly limits promotion** drew significant engagement, with users comparing throughput on Free vs. Pro vs. Max plans and mapping out optimal workflows given the limits.
