# Claude Weekly Update — June 8, 2026

> Covering: June 1–8, 2026

---

## Shipped: New Features & Changes

### Claude Opus 4.8 (Released May 28)
Anthropic launched **Claude Opus 4.8**, now the default model on Max, Team Premium, Enterprise pay-as-you-go, and the API. Key improvements over Opus 4.7:

- **SWE-Bench Pro**: 69.2% — beats GPT-5.5 and Gemini 3.1 Pro on this benchmark
- **USAMO 2026**: 96.7% (up from 69.3% on Opus 4.7 — a +27.4 pp gain in 41 days)
- **Fast Mode**: 2.5× faster, now 3× cheaper than previous fast mode pricing
- **Effort Control**: Users can dial the amount of reasoning the model applies per task
- **Improved honesty**: More likely to flag uncertainties and avoid unsupported claims; better judgment in agentic settings
- Pricing unchanged at $5/M input tokens and $25/M output tokens

### Claude Code — Agent & CLI Polish
Multiple improvements to the Claude Code CLI and desktop experience this week:

- **Agent View**: New multi-session manager in the CLI — start agents, send them to background, peek at status and last responses, and jump back in only when input is needed
- **`ant` CLI**: New command-line client for the Claude API with native Claude Code integration and YAML-based versioning of API resources
- **Startup & session polish**: Better JSON status, more reliable permissions and tool behavior, clearer warnings, smoother session handling, quieter launches on native and Windows builds
- **Rate limits doubled** for Claude Code; API limits for Claude Opus raised as well

### Claude Desktop — Cowork GA
**Claude Cowork** is now generally available on macOS and Windows via Claude Desktop (rolling out to Max plans first, then Pro over two days):

- Persistent agent threads for managing long-running tasks
- Create/schedule recurring and on-demand tasks
- Inline chart, diagram, and visualization generation
- New **Customize** section consolidating skills, plugins, and connectors

### Microsoft 365 Integration — GA
Claude's M365 add-ins for **Excel, PowerPoint, and Word** are now generally available on paid plans. **Outlook** is in public beta, with inbox triage and draft-reply support and context sync across open files.

### Legal MCP Connectors
20+ new legal MCP connectors and 12 practice-area plugins released, covering research, contracts, discovery, matter management, and legal aid for law firms and in-house teams.

## Announced But Not Yet Released

### Dynamic Workflows (Research Preview)
A **Dynamic Workflows** feature is in research preview for Max, Team, and Enterprise plans via Claude Code CLI, Desktop, and the VS Code extension. Designed for tasks too large for a single conversation — Claude writes an orchestration script and fans it out across hundreds of parallel subagents, then verifies outputs before reporting back. Use cases: codebase-wide audits, large migrations, cross-referenced research.

### Self-Hosted Sandboxes (Public Beta)
Tool execution can now move to **your own infrastructure** (or a managed provider like Cloudflare, Daytona, Modal, or Vercel) while the agent loop stays on Anthropic's infrastructure. Public beta — supported providers expanding.

### Claude Managed Agents — Multiagent Orchestration
- **Dreaming**: A scheduled process that reviews past agent sessions, surfaces patterns, and curates memory so agents improve between runs
- **Multiagent orchestration**: Lead agent delegates to specialist subagents working in parallel on a shared filesystem, each with its own model, prompt, and tools

### Project Glasswing Expansion
Anthropic extended **Claude Mythos Preview** access to ~150 new organizations and added **Claude Security** for codebase scans and automated patch suggestions under Project Glasswing.
