# Claude Weekly Update — August 24, 2026

> Covering Claude Desktop and Claude Code updates from the past 7 days (2026-08-18 to 2026-08-24).

## Claude Code — Shipped

A busy release week: six versions shipped (2.1.236 → 2.1.241), with two headline features, a raft of quality-of-life additions, and roughly 150+ bug fixes.

### "Concise" Output Style (v2.1.237, August 20)
A new built-in output style where **Claude leads with results and skips preamble** while still doing thorough work. Selectable from `/output-style`.

### Cross-Session `notify_when_idle` (v2.1.236, August 19)
`SendMessage` now accepts `notify_when_idle` so one Claude Code session can ask another to ping it the moment it goes idle — one-shot, no polling. macOS/Linux only for now.

### `ANTHROPIC_DEFAULT_MODEL` (v2.1.236, August 19)
New env var that sets the model new sessions start on (still overridable via `/model`). Useful for teams standardizing on a specific tier.

### Readline-Style Keybindings (v2.1.238, August 20)
New `keybindingFlavor: "readline"` setting gives Bash-style behavior — e.g. **Ctrl+W deletes to the previous whitespace** instead of the previous word boundary.

### Plugin Marketplace `headersHelper` (v2.1.238, August 20)
URL marketplaces and catalog entries can now mint HTTP headers (e.g. short-lived tokens) via a `headersHelper` command. Runs with a `[y/N]` confirmation on install/update.

### Self-Hosted Runner Ergonomics (v2.1.238, August 20)
Two new flags for `claude self-hosted-runner`:
- `--defer-shutdown-max-min <minutes>` — keep serving attached sessions before parking.
- `--proxy-authorization-command` / `--proxy-authorization-file` — for egress proxies that need fresh auth headers.

### `/claude-api upgrade` — Python SDK Migration (v2.1.239, August 21)
New command that migrates Python projects from the `anthropic` 0.x SDK to 1.x automatically.

### Data-Residency Cost Transparency (v2.1.239, August 21)
`/cost`, the status line, and `--max-budget-usd` now include the **1.1× US-only-inference premium** for data-residency workspaces, so estimates match the invoice.

### Broader Platform Coverage (v2.1.239, August 21)
- Fullscreen renderer offer now appears on **Bedrock, Vertex, Foundry**, and other setups previously excluded.
- **Alpine/musl builds** load the native image-paste, clipboard, and audio-capture add-ons.

### Synced Plugins Get a Namespace (v2.1.239, August 21)
Plugins synced from claude.ai now show as `name@synced` and are addressable via `claude plugin enable/disable <name>@synced`. Synced plugins never override same-named locally-installed ones — no more silent shadowing.

### VS Code: Session Groups
Right-click the sidebar sessions list to **create, rename, and delete groups** — useful when juggling many concurrent sessions.

### Overwrite-Without-Read on Newer Models
On newer models, Claude may overwrite an existing file with the Write tool without reading it first in the same session, trimming a redundant round-trip.

### Auto-Continue When Limits Reset (from v2.1.234, still landing this week)
Sessions can automatically pick back up the moment the usage-limit window resets — the message now tells you *when* the session/weekly limit resets.

### Bug Fix Highlights (worth flagging)
- **Prompt caching fixed** for sessions using LLM gateways or custom base URLs (v2.1.237).
- **Subagent memory leak fixed** — tool results are now released after leaving the display window (v2.1.238).
- Fixed Edit/Write pausing ~5s in JetBrains IDE terminals.
- Fixed WebFetch retaining expired content for the whole session.
- Fixed cloud sessions resuming out of plan mode.
- Fixed `/goal` check-ins repeating every 30 min instead of backing off, and not restoring the active goal on resume.
- Fixed `ListAgents` not listing live teammates.
- Fixed Vim mode losing text on Escape.
- Fixed `.md` files with a UTF-8 BOM being silently ignored.

Full detail: v2.1.239 alone shipped 40+ fixes covering proxies, MCP, cloud sessions, and terminal rendering.

## Claude Desktop & Platform — Shipped

### Claude Academy Launches (August 20)
Anthropic opened **[academy.claude.com](https://academy.claude.com)** — a free learning hub with **26 courses and ~355 tutorials/prompting tips/use-case examples** covering Claude, Cowork, Code, Tag, and the API.

Learning paths:
- **Start Your Journey** and **Become AI Fluent** — non-technical.
- **Learn the Products** and **Build with the API** — developer-focused.

Every course is free; only an email is required to sign up. This is the successor to the earlier "Anthropic Academy" (launched March 2, 2026 on Skilljar) — now on a dedicated domain and roughly 2× the content.

### Cowork Continues Rolling Out
Cowork on **web and mobile** (announced last week, Max plan first) keeps rolling out. No new platform gates opened this week, but the desktop → web/mobile parity story is now the default in Anthropic's marketing.

### Reflect + Memory
The **Settings → Reflect** monthly recap (topics, active days, peak hours, work-style observations) remains in beta on Free, Pro, and Max — web + Desktop, memory required. No feature changes this week; just steadily wider availability.

## Research & Announcements

### Claude Designs Working Protein Binders (August 18)
Anthropic published research: Claude (**Mythos Preview** and **Opus 4.8**) designed protein binders against 15 targets and **succeeded on 14**. Individual-design hit rates ran **22–35%** vs. the typical 10–15% in the field. Against RBX1, Mythos Preview hit **40%** vs. 3.7% among competition participants.

A single Claude agent — operating under an expert-set protocol — handled target research, tool selection, candidate narrowing, and sequence ranking. Two outside firms (**Adaptyv Bio** and **Twist Bioscience**) independently synthesized and tested the designs.

Notably, this is the same "agent runs the whole pipeline" pattern Anthropic has been pushing in Claude Code and Cowork, applied to wet-lab science. Builds on the Claude Science workbench that launched June 30.

## Community Buzz

- Anthropic's own [@claudeai account](https://x.com/claudeai) highlighted a curated list of "favorite Claude Code projects lately" — the momentum continues to be around agentic builds, not just chat.
- A **Google principal engineer's post** claiming Claude Code compressed an hour of engineering work into minutes hit **Hacker News** and drove another round of "is this real?" threads. Consensus in comments: yes, for well-scoped tasks; still needs supervision.

Overall tone: still very high energy, with the conversation shifting from "look what it can do" to "how do I run this at scale without burning limits."
