# Claude Weekly Update — August 31, 2026

> Covering Claude Desktop and Claude Code updates from the past 7 days (2026-08-25 to 2026-08-31).

---

## Claude Code — Shipped

### v2.1.250 — Bug Fixes & Reliability (August 27)
This week's headline release was a stability-focused point release. After a heavy feature period spanning built-in browser, `/design`, Remote Control device cards, and self-hosted environments, the team shifted emphasis to reliability and polish. No new headline features; roughly the same "plumbing" focus as the prior cycle's v2.1.239 mega-patch.

### Session Security & Sandboxing Hardening
Claude Code shipped tightened session hooks, expanded permissions controls, and stricter sandbox protections — part of an ongoing push to make agentic sessions safer by default, especially for enterprise deployments.

### Live Remote Control Streaming for Foreground Subagents
Foreground subagents in Remote Control sessions now stream output live, so watchers on a phone or secondary terminal see real-time progress rather than waiting for the agent to finish before output appears.

### Richer Usage & Cost Visibility
Additional cost-transparency improvements landed this week, building on the v2.1.239 data-residency premium work. The per-task token breakdown (introduced in v2.1.243 earlier this month) continues to get refinements.

### New CLI Commands
Several new `claude` CLI subcommands shipped — specifics undisclosed in public changelogs, but noted in the Releasebot summary as part of the broad session and tooling improvements this week.

## Claude Desktop & Platform — Shipped

### Memory Arrives Everywhere (August 25)
Anthropic made a formal cross-surface memory announcement: **Claude's memory now works everywhere, and you control what's in it.** This covers Claude Desktop, Claude Code, the web app, and mobile. The announcement marks memory moving out of gradual rollout and into a fully stated, user-managed feature across all surfaces.

Key controls surfaced:
- Users decide what goes into memory (explicit saves, not passive capture).
- Memory is visible and editable in Settings.
- Works consistently whether you're in Desktop, Code, or a browser session.

### Built-in Browser Panel (Continuing Rollout)
Claude Desktop's native browser panel — which lets Claude open websites, read pages, click, and type without touching the user's personal browser — continues rolling out to Pro, Max, Team, and Enterprise on macOS, Windows, and Linux. No new gates opened this week, but availability is widening.

### Enterprise Security Add-on Checker
The beta Enterprise add-on scanner (automatic malicious-content checking for installed add-ons) is now available to Enterprise customers. No changes this week, but noted as reaching stable beta status.

## Pricing Note

### Claude Sonnet 5 Launch Pricing Ends (August 31)
Anthropic's introductory rate for Sonnet 5 — **$2 input / $10 output per million tokens** — reverts to the standard **$3/$15** rate today. Not a Desktop/Code feature, but relevant to anyone running agentic Claude Code workflows through the API; review your `--max-budget-usd` limits and cost estimates accordingly.

## Community Buzz

- The **"/design skill"** (artboard-based UI design in Claude Code, shipped August 17-21) is generating significant community interest — people are using it to prototype entire product flows without touching Figma.
- The **Remote Control device cards** feature (any machine running `claude remote-control` appearing as a card on your phone) continues to attract attention from developers running long background agents — the ability to attach mid-session from mobile is proving more useful than expected.
- Community discussion around **`ANTHROPIC_DEFAULT_MODEL`** is picking up as teams look to standardize fleets of Claude Code sessions on a specific model tier without per-session configuration.
- Memory's expanded cross-surface availability is drawing renewed interest — particularly from developers who want their coding context in Claude Code to carry into Claude Desktop conversations and vice versa.
- Continued conversation around **session costs after Sonnet 5 pricing normalization**: teams tracking spend closely, with the per-task token breakdown and data-residency transparency features being cited as essential tools for staying within budget.
