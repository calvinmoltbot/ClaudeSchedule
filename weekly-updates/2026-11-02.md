# Claude Desktop & Claude Code Weekly Update
**Week of October 26 – November 2, 2026**

---

## New Features Shipped

### Claude Desktop / Claude App

- **Monthly Reflect recap (beta):** A new monthly recap under Settings → Reflect shows topics you spent time on and your most active day. Available in beta on Free, Pro, and Max plans on the web and Claude Desktop.
- **Cowork GA on macOS & Windows:** Cowork is now generally available through the Claude Desktop app on both macOS and Windows, no longer limited to certain plans.
- **Dashboards and Motion (beta, expanded):** Both features — Dashboards for live data pages and Motion for animated content — are in beta and rolling out to more users following their initial Team/Enterprise beta launch in early October.

### Claude Code CLI

- **Stop/SubagentStop hooks can return `additionalContext`:** Hook scripts exiting on a stop event can now include `hookSpecificOutput.additionalContext` in their JSON output, sending feedback back to Claude without triggering a hook error. Useful for surfacing status messages and summaries from custom tooling.
- **Fallback model across the full session:** When the primary model is not found (unavailable or rate-limited), Claude Code now switches to your `--fallback-model` for the entire rest of the session rather than failing per-request.
- **Idle compaction:** Conversations exceeding ~200K tokens that go idle are now automatically summarized. On your next message, if the prompt cache has expired, Claude picks up from the summary instead of losing context or hitting token limits.
- **New environment variables:**
  - `CLAUDE_CODE_DISABLE_ULTRATHINK` — disables the ultrathink extended-thinking mode when set.
  - `CLAUDE_CODE_SUBAGENT_EFFORT` — sets a default reasoning effort level for subagents, enabling cost-sensitive multi-agent pipelines.
  - `CLAUDE_CODE_AUTO_MODE_MODEL` — selects the model used by the client-side auto mode classifier (added Oct 16, rolling into broader availability this week).

## Announced but Not Yet Released

- **Opus 4.8 Fast Mode deprecation:** Fast mode for Opus 4.8 is deprecated as of October 30, 2026 and will be **removed on November 30, 2026**. Users relying on it should migrate to Opus 5.5, which supports fast mode and is generally available.
- **Claude Duet:** Still in research preview / waitlist as of late October. No general availability date announced.

---

## Community Buzz & Interesting Use Cases

- **Persistent automation:** The idle compaction and background task features are enabling new "always-on" workflows — users are sharing setups that watch deploys, poll pull requests for review, and periodically check application logs without keeping a terminal open.
- **Multi-agent review pipelines:** Teams are building multi-agent review flows using Claude Code workflows, with separate subagents specializing in security, performance, and business logic, then consolidating findings.
- **Cost routing with `CLAUDE_CODE_SUBAGENT_EFFORT`:** Early adopters are using the new env var to route routine subagent work to lower-effort (cheaper) settings while keeping the main orchestrator at full effort — reportedly cutting costs significantly on large agentic runs.
- **Frontend screenshot-to-component:** Sharing of workflows that drop a Figma export or browser screenshot and get a working React or Vue component back in one prompt continues to grow as a popular beginner use case.
- **Plugin ecosystem:** Community plugins like `claude-music` (adding `/play` and `/vibe` commands) continue to appear in third-party marketplaces, reflecting growth in the plugin ecosystem following the marketplace launch earlier this year.
