# Claude Weekly Update — June 15, 2026

> Covering: June 8–15, 2026

---

## Shipped: New Features & Changes

### Claude Fable 5 — Released June 9 (then suspended, see below)
Anthropic's most capable publicly released model shipped on June 9, with impressive specs:

- **Always-on adaptive thinking** — reasoning is automatic, not opt-in
- **1M-token context window**, 128K output tokens
- State-of-the-art benchmark results across nearly all tested categories
- Built-in safety classifiers that automatically fall back to Claude Opus 4.8 for flagged requests

The model was available for three days before the US government intervened (see "Major Story" section below).

### Claude Code — Dynamic Workflows Now in Research Preview
Dynamic Workflows moved from announcement to research preview this week for **Max, Team, and Enterprise** plans:

- Activate by asking Claude directly, or toggle the new **"ultracode" setting** to let Claude decide when to use workflows automatically
- Designed for tasks too large for a single conversation — Claude fans work out across hundreds of parallel sub-agents, then verifies outputs before reporting back
- Available in Claude Code CLI, Desktop, and the VS Code extension

### Claude Code — Nested Sub-Agents & Platform Polish
Additional Claude Code updates shipping this week:

- **Nested sub-agents**: Lead agents can now spawn specialist sub-agents working in parallel on a shared filesystem, each with their own model, prompt, and tools
- **Smarter model and region handling**: Automatic fallback and routing improvements
- **New plugin search**: Easier discovery of connectors from within the tool
- **Better Chrome, VS Code, and terminal workflows**: Reduced friction switching between environments

### Claude Desktop — Improved MCP Accessibility
MCP connections are now easier to configure for non-developers directly from the Claude Desktop app, letting Claude read local files, query databases, and interact with web services without requiring manual config editing.

### API Model Retirements — Effective June 15
Two original Claude 4 models are retired from the API today:

- `claude-sonnet-4-20250514`
- `claude-opus-4-20250514`

Teams still on these model strings need to migrate. Recommended replacements: `claude-opus-4-8` or the appropriate Fable/Sonnet variant depending on use case.

## Major Story: Fable 5 & Mythos 5 Suspended by US Government

On **June 12**, just three days after launch, Anthropic received a letter from the US government citing national security authorities, directing it to **suspend all access to Claude Fable 5 and Claude Mythos 5** by any foreign national — including foreign national Anthropic employees based in the United States.

Key facts:

- Because Anthropic cannot filter foreign nationals from US users in real time, it shut **both models down for all customers** to ensure compliance
- The trigger cited was an alleged jailbreak in which a user could ask Fable 5 to "read a specific codebase and fix any software flaws" — though no specific national security concern was detailed in the letter
- Anthropic is complying, but publicly called the underlying finding a **"misunderstanding"** and warned that the same standard applied industry-wide would halt every frontier model release
- **Claude Opus 4.8** remains the default fallback model on all plans

This is a developing story. Watch Anthropic's newsroom for updates on when/if Fable 5 access resumes.

## Announced But Not Yet Released

### Managed Agents — "Dreaming" Feature
The **Dreaming** feature for Claude Managed Agents (announced in preview) is rolling out gradually: a scheduled background process that reviews past agent sessions, surfaces patterns, and curates agent memory so performance improves between runs without manual prompting.

### Self-Hosted Sandboxes
Tool execution can move to your own infrastructure (or a managed provider: Cloudflare, Daytona, Modal, Vercel) while the agent loop stays on Anthropic's side. Public beta expanding to more providers.
