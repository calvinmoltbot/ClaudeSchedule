# Claude Desktop & Claude Code Weekly Update
**Week of June 16–22, 2026**

---

## New Features & Changes Shipped

### Claude Fable 5 — General Availability (June 9)
Anthropic released **Claude Fable 5**, a Mythos-class model now available for general use. Key specs:
- Always-on adaptive thinking
- 1-million-token context window
- 128K output tokens
- Built-in safety classifiers that automatically fall back to Claude Opus 4.8 for flagged requests (cybersecurity, biology, etc.)

> **Important:** On June 12, Anthropic received a US government export-control directive and was required to **suspend access to both Claude Fable 5 and Claude Mythos 5**. The situation is ongoing.

---

### Claude Code — Agent & Workflow Improvements
- **Nested sub-agents:** Sub-agents can now spawn their own sub-agents, up to **5 levels deep**, enabling larger multi-step orchestration.
- **`/cd` command:** Move a session to a new working directory mid-conversation without rebuilding the prompt cache.
- **Artifacts (beta):** Turns session work into live, shareable web pages (PR walkthroughs, incident dashboards, checklists). Available to Team and Enterprise orgs from the CLI and desktop app.
- **Auto-mode safety improvements:** Clearer model deprecation warnings, refined toggle behavior, `/config` help, and reduced startup clutter.
- **Bug fixes:** Wide-ranging fixes across subagents, WebSearch, TUI display, tmux, background tasks, and task notifications.

---

### Claude Design ↔ Claude Code Sync
- Claude Design is now available in the **sidebar of the Claude desktop app** and at `claude.ai/design`.
- **`/design-sync`:** Bi-directional sync between Claude Design and Claude Code — pull your design system into your repo, or push built components back into Claude Design.
- Importable design systems, real canvas editing, and stronger layout controls round out the update.

---

### Platform & API
- **Rate limits doubled** for Claude Code; API limits raised for Claude Opus — targeting developers, startups, and enterprises.
- **Workload Identity Federation (GA):** Keyless authentication across API endpoints, SDKs, and Claude Code. Adds service accounts, guided setup, and Admin API support.
- **Enterprise-managed MCP connectors:** Admins provision connectors once (starting with **Okta**); users get zero-touch access on first login.
- **Claude Managed Agents — new capabilities:**
  - *Dreaming:* Scheduled process that reviews past sessions, surfaces patterns, and curates memory so agents improve between runs.
  - *Multiagent orchestration:* Lead agent delegates to specialist subagents on a shared filesystem, each with its own model, prompt, and tools.
  - *Private MCP support:* Agents can now run in a sandbox you control and connect to your own MCP servers.
- **Developer Platform tool updates:** New versions of code execution, web search, and web fetch tools; `response_inclusion` to trim consumed result blocks for agentic workflows; 90-second per-cell limit for long-running code now exposed.
