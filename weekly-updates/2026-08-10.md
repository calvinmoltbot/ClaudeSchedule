# Claude Desktop & Claude Code Weekly Update — August 10, 2026

## New Features & Changes Shipped

### Claude Code

- **v2.1.221 — Focus view (August 3)** — A new Focus view in the VS Code extension collapses tool activity into compact summaries, decluttering the chat interface during long agentic runs.
- **v2.1.223 — Permission-check hardening (August 5)** — Security fix preventing commands from hiding themselves from permission checks; closes a gap in earlier auto-approval logic.
- **v2.1.224 — Self-hosted environments (August 7)** — Sessions can now run on your own machines via self-hosted environments, giving teams full control over where code executes without routing through Anthropic cloud infrastructure.
- **v2.1.225 — Gateway spend-limit enforcement (August 7)** — Claude Code now respects gateway spending limits and surfaces clear notifications showing your cap and reset time. Critical authentication fixes also included.
- **v2.1.226 — Bug fixes and reliability (August 8)** — General stability and reliability improvements.
- **`/deep-research` is now manual-only** — The `/deep-research` command no longer launches automatically; it must be explicitly invoked, giving users more control over when deep research sessions start.
- **Screen-reader announcements for deleted text** — Accessibility improvement: deleted text is now announced in screen-reader mode.
- **Archive plugin sources** — Plugins can now be installed from a zip over HTTPS, removing the requirement for git or npm.

### Claude Desktop

- **Monthly Recap (beta, rolling out)** — `Settings → Reflect` shows a monthly summary: topics you worked on, most active day, peak hour, and observations about your working style. Available in beta on Free, Pro, and Max plans on web and Claude Desktop (memory must be on).
- **Break reminders & quiet hours** — `Settings → Time and focus` lets you configure optional break reminders and quiet hours within Claude Desktop.
- **Cowork on web and mobile (expanded)** — Cowork remote sessions now run on web and mobile in addition to desktop, with files and session state saved to your Claude account and synced across devices (rolling out to Max users).

### MCP Ecosystem

- **MCP spec 2026-07-28 fully supported** — Claude now fully supports the new MCP spec: stateless core, stronger OAuth/OIDC authorization, versioned extensions for Apps and Tasks, embedded UI, enterprise-managed auth, observability hooks, and private network tunnels.
- **950+ MCP servers in the connectors directory** — The connector ecosystem continues to grow, now listing over 950 MCP servers used by millions of people daily.

## Community Buzz & Interesting Use Cases

- **Scheduled cloud tasks gaining traction** — Developers are increasingly using Claude Code's cloud scheduling (set a repo, schedule, and prompt) to run autonomous tasks without keeping a local session open. The pattern of "fire and forget" agent fleets is becoming the norm among power users.
- **Claude Code channels via MCP** — Community members are wiring Claude Code sessions to messaging platforms (Telegram, Discord) through MCP connectors, enabling session control and approval prompts directly from a phone.
- **Autonomous research pipelines** — A popular demo making the rounds: a three-search-engine research pipeline orchestrated entirely by Claude Code, set up in under 15 minutes, returning structured reports without human intervention.
- **Growing "agent-first" workflow shift** — Community sentiment on r/ClaudeCode reflects a broader shift: many developers have moved from reviewing every agent step to running multiple parallel agents without inspecting intermediate results, signaling high confidence in Claude Code's judgment.
- **Anthropic webinar: "What We Shipped"** — Anthropic hosted a live Q&A with the Claude Code team covering recent feature releases and roadmap — recordings available on the Anthropic partner webinar series page.
