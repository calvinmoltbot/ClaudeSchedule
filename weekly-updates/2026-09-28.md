# Claude Desktop & Claude Code: Weekly Update
**Week of September 22–28, 2026**

---

## New Features Shipped

### Claude Code

- **Claude Opus 5.5 as Default Model** (v2.1.280): The new default model brings a 1M token context window, 128k max output tokens, always-on adaptive thinking, and improved mouse controls.
- **Auto-mode efficiency** (v2.1.278): Auto mode now defaults to server-side processing for most users, reducing extra charges significantly.
- **`claude plugin eval`**: A new tool for running plugins against test cases, scoring results, and comparing against a no-plugin baseline — makes plugin development easier to validate.
- **Pop-out panes**: Any Claude Code Desktop pane can now be undocked into its own window and docked back later, improving multi-monitor workflows.
- **Broader gateway & MCP controls**: New controls spanning gateway, MCP, plugin, workflow, and `/doctor` audit; plus faster startup and latency improvements.
- **Richer list/terminal navigation**: Lists now support PgUp/PgDn, Home/End, mouse wheel, and click navigation.
- **Cross-session messaging**: `ListAgents` discovers reachable sessions; `SendMessage` lets sessions exchange findings directly and notify when another session becomes idle. Includes explanations of prompt cache behavior.
- **Cache miss diagnostics**: Building on August's cache meter, September added "likely miss causes" to help investigate cache misses.
- **Improved `/artifacts`**: Titles line up in a single column, details drop whole instead of cut mid-word.
- **Bug fixes**: Better fullscreen mouse support, stronger MCP controls, cleaner dialogs, VS Code session archiving, and many fixes across sandboxing, Windows, and Claude Tag.

### Claude Desktop / Claude.ai

- **New unified Claude experience** (rolling out): Everything available from any conversation — quick questions or bigger Cowork tasks (reports, spreadsheets, presentations) without choosing a mode first. Chats, Cowork tasks, projects, connectors, and skills carry over. Rolling out gradually to Pro and Max plans on web, desktop, and mobile.
- **Claude Tag expansion**: Users can now use their own personal connectors in Slack channels (not just admin-attached shared tools). Adds review or auto mode for posting, stronger admin governance for Enterprise, with rolling rollout on Team plans.
- **Windows workspace fix**: A Windows update (released Sept 8) blocked Claude's workspace from accessing files — this has been patched. Also fixed: Office file preview display issues, authentication errors during long-running tasks when sign-in renews in the background.
- **Unknown-model error improvement**: Better error messaging suggests switching to a different model; improved rendering of unusual Unicode in permission prompts.

### Claude Developer Platform

- **Claude Opus 5.5 launch**: Available for long-running agentic coding and knowledge work — 1M token context, 128k output tokens, always-on adaptive thinking.
- **Plugins as first-class extensions**: Plugins are now the main way to build third-party extensions. New features: directory submission portal, auto-validation, review status, publishing controls, and post-launch analytics.
- **MCP 2.0 + MCP Apps support**: Including Enterprise Managed Auth for richer plugin experiences.
- **Inline tools in mid-conversation system messages**: New beta support added to the developer platform.

## Announced but Not Yet Released

- The new unified Claude experience is **rolling out gradually** to Pro and Max plans — not everyone has it yet.
- Claude Tag on **Team plans** is in a rolling rollout; Enterprise governance features still expanding.

## Community Buzz & Interesting Use Cases

- **Multi-file refactoring**: Reddit's r/ClaudeCode consistently highlights Claude Code's ability to track dependencies across 10+ files during large refactors — users report it outperforms ChatGPT and Copilot on this.
- **Real-time research**: One developer used `/last30days` to pull 78 Reddit threads, 76 X posts, 22 YouTube videos, and 15 Hacker News stories in minutes, producing a grounded technical plan for choosing between Vercel's agent-browser and Playwright.
- **Dialogue-based debugging**: Developers describe Claude Code as the clear leader for interactive debugging — you describe the error, Claude explains the *reasoning*, not just the fix.
- **Large codebase navigation**: The 1M token context window in Opus 5.5 is generating significant excitement for monorepo and enterprise codebase work.
- **r/ClaudeCode growth**: The subreddit crossed 4,200+ weekly contributors — more than triple the 1,200 on r/Codex — signaling strong developer adoption momentum.
