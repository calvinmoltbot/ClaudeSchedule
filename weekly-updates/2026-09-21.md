# Claude Weekly Update — September 21, 2026

> Covering Claude Desktop and Claude Code updates from the past 7 days (2026-09-14 to 2026-09-21).

---

## Claude Desktop & Platform — Shipped

### Projects Redesigned: From Folder to Conversation (September 17) ⭐
The biggest UX change this week: Projects have been redesigned around a conversation model rather than a folder/document model. One project can now coordinate **parallel threads, shared memory, and a project library** — describe what needs to get done and Claude manages the work distribution. This is a significant shift from Projects as a static file container to Projects as a live coordination layer.

### Cowork and Chat Are Now One Claude (September 16) ⭐
Anthropic merged the previously separate Claude Cowork and Claude chat interfaces. The unified app presents a single entrypoint for both conversational and agentic (computer-use) workflows. Key changes:
- Cowork sessions and chat conversations share the same project context
- Switching between conversational help and computer-use no longer requires navigating to a separate surface
- Simpler for new users who were confused by two distinct products

### Small Business Workflows & Integrations Launch
Anthropic launched an expanded set of SMB-focused workflows and connectors:
- **43 new workflows** covering lead generation, proposals, reporting, and back-office tasks
- **27 new connectors** including Shopify, Salesforce, Zoom, Xero, Gusto, Square, Stripe, and Zapier
- Expands Claude's SMB utility beyond general assistance into structured business processes

### Financial Advisor Plugin in Cowork
The Claude for Financial Advisors plugin is now available in Cowork. Firms that request a new license before end of September 2026 receive a one-time usage credit.

### Smart Reports (Enterprise Beta)
Enterprise plans can now access Smart Reports, a new analytics feature that analyzes:
- Team usage patterns and costs
- Points of friction in agentic workflows
- Reusable shared skills across the organization

Currently in beta; no GA date announced.

### Messages API On-Demand Compaction (Beta)
The API now supports compacting a conversation on demand via the `compact-2026-09-04` beta header. Send the `compaction` parameter and the API returns a signed compaction block summarizing the messages — useful for long agentic sessions that need to manage context length without losing continuity.

## Claude Code — Shipped

### v2.1.265–v2.1.271 — Feature and Fix Run (September 14–21)
A busy release week across patch versions:

- **Fast mode in remote sessions** — the Opus fast-mode toggle now works in web and remote Claude Code sessions, not just local CLI
- **Per-command Bash domains** — you can now configure domain allowlists at the individual Bash command level, giving finer-grained network control in automated workflows
- **Diff panel in fullscreen** — the diff/patch panel is now accessible in fullscreen terminal mode without dropping back to windowed view
- **Cache diagnostics** — new diagnostic output when prompt cache behaves unexpectedly (cache miss on a known-warm context, cache invalidation mid-session)
- **Pasted and attached images saved as files** — images pasted into Desktop or VS Code are now saved to disk so Claude can open them without extra permission prompts
- **Terminal responsiveness** — output no longer falls further behind when the terminal is slow or paused; Claude's output pauses at the terminal's pace instead of buffering ahead
- **Artifact tool guidance** — Claude now correctly updates a shared artifact in place when given edit access, rather than publishing a duplicate copy

## Community Buzz

- **Projects redesign** is generating the most discussion this week. Developers are excited about parallel thread coordination; some long-time users are re-evaluating their project organization after years of the folder-centric model. The framing of "describe the work, Claude manages it" is landing as a meaningful capability upgrade.

- **Cowork/chat unification** getting mixed initial reactions — experienced Cowork users note that some power controls are temporarily harder to reach in the unified UI, while new users find it much more approachable.

- **Per-command Bash domains** is a quiet but widely appreciated addition among developers running Claude Code in CI/CD pipelines with strict egress policies.

- **Community troubleshooting hot topics this week:**
  - A Windows Update conflict crashing Plan9 shares is affecting a subset of Claude Code Desktop users on Windows; Anthropic has acknowledged the issue
  - macOS local network permission changes are blocking remote SSH operations for some users — a macOS-level prompt that many missed on upgrade

- **SMB workflows launch** is getting attention in the small business and startup community — particularly the Shopify and Stripe connectors enabling Claude to take action on e-commerce and payment data directly.

- **API compaction** feature is drawing interest from developers building long-context agentic systems; early reports suggest it significantly reduces token overhead for iterative reasoning loops.
