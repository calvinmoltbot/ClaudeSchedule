# Claude Desktop & Claude Code Weekly Update
**Week of June 23–29, 2026**

---

## New Features & Changes Shipped

### Claude Code v2.1.187 (June 23)
The week's headline release brought several quality-of-life and security improvements:
- **`sandbox.credentials` setting:** Block sandboxed commands from reading credential files and secret environment variables — a targeted hardening option for teams running untrusted code.
- **Org-configured model restrictions:** Admins can now restrict which models are available within an organization directly from the platform.
- **Mouse click support in fullscreen mode:** Click to select menus (permission prompts, `/model`, `/config`, etc.) instead of relying solely on keyboard navigation.
- **Bug fixes:** `--resume` no longer fails with "No conversation found" when the original `-p` run produced no model turns; `--json-schema` and `workflow agent({schema})` structured output now work correctly.

---

### MCP Authentication from the Shell
- **`claude mcp login`:** Authenticate a configured MCP server directly from your shell instead of going through the interactive `/mcp` menu.
- **`claude mcp logout`:** Clear stored credentials for a server when you no longer need access.

---

### Shell Mode & Conversation Flow Improvements
- **Shell mode responds to command output:** Running `npm test` now gets Claude's explanation automatically, without a second prompt.
- **`/rewind` command:** Resume a conversation from before `/clear` was run — previously lost context is now recoverable mid-session.
- **Background subagents surface prompts:** Instead of auto-denying, background subagents now route permission prompts to the main session so you can approve or deny interactively.

---

### Performance
- **~37% CPU reduction during streaming:** Measured improvement to CPU usage while streaming responses; meaningfully reduces fan noise and battery drain on laptops.

---

### Trusted Devices for Remote Control (Team & Enterprise)
Admins can now require members to verify their device before viewing or steering local Claude Code sessions remotely. Adds a hardware-bound verification step before granting remote access.

---

### Slack Integration
Team and Enterprise plan users can now **tag Claude directly in Slack** conversations to delegate tasks while staying focused on other work. Claude responds in-thread and can access project context.

---

### Advanced Agent Architecture
- **Hierarchical agent spawning (3 levels deep):** A parent agent can create child agents, each of which can spawn its own children — up to three levels. Enables layered task decomposition across modules and files.
- **Fallback model chains:** Define a sequence of fallback models; if the primary model is unavailable or rate-limited, Claude Code steps down the chain automatically.
- **Per-agent cost attribution:** Each spawned agent's token consumption is tracked and reported separately, making multi-agent workflows auditable.
- **Scoped permissions:** Grant individual agents a specific subset of tool permissions rather than inheriting the full parent session's capabilities.

---

### Claude Compliance API Integrations
Anthropic launched integrations with notable security and compliance tooling, allowing IT and security teams to govern Claude across the full product suite using the same controls they apply to other enterprise applications.

---

## Announced but Not Yet Released

- **Dynamic Workflows credits requirement:** Dynamic Workflows were free for all Pro/Max/Team/Enterprise users from June 9–22. **From June 23 onward**, further use draws from usage credits. Full pricing and credit packages have not yet been detailed.
- **Community tool marketplace:** Referenced in release notes and third-party coverage but not publicly launched as of June 29.
- **Fable 5 / Mythos 5 restoration** — Still pending. The US government export-control directive issued June 12 has not been lifted; both models remain suspended.

---

## Community Buzz & Interesting Use Cases

- **Hierarchical agents for large refactors:** Developers are using the new 3-level agent nesting to tackle monorepo migrations — a lead agent coordinates module-level agents, each of which spawns file-level agents. Several write-ups on GitHub Discussions show end-to-end migrations completing in under an hour.
- **n8n orchestration via MCP:** Teams are connecting Claude Code to n8n through MCP servers, letting Claude trigger workflows, read execution logs, and adjust runs without leaving the terminal. Popular for CI/CD pipelines and data processing jobs.
- **`/rewind` as a debugging tool:** The community quickly picked up `/rewind` not just for undo but as a branching mechanism — rewinding before a bad prompt and trying a different approach, effectively turning linear sessions into lightweight explorations.
- **Business automation with computer use:** Most-cited use cases this week: LinkedIn outreach automation, ad campaign management, and government form filing — all leveraging Claude Code computer use with MCP tool access.
- **SitePoint's "10 New Features" guide** (June 2026) is circulating widely among backend developers who hadn't tried Claude Code CLI before; notable onboarding spike reported.
