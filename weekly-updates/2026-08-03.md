# Claude Desktop & Claude Code Weekly Update — August 3, 2026

## New Features & Changes Shipped

### Claude Code
- **`/code-review` as background subagent** — Review work now runs in a background subagent so it no longer fills your conversation context.
- **Screen reader improvements** — `--ax-screen-reader` mode now announces deleted text, improving accessibility in live sessions.
- **Live elapsed-time counter** — Collapsed tool summary lines now show a ticking timer for long-running calls, giving visibility into stuck or slow tools.
- **"Always allow" permissions persist across worktrees** — Permission rules now save at the repository root, so approvals survive across git worktrees.
- **MCP & Windows path fixes** — Several fixes to MCP connector handling and Windows path resolution landed this cycle.
- **Safer auto mode** — Auto mode now correctly respects `PreToolUse` hook decisions; previous behavior could bypass hook outcomes.
- **Parallel session logout fix** — Fixed a bug causing logout across parallel sessions after wake-from-sleep.
- **Plugin MCP server reconnection** — Plugin MCP servers now reconnect properly after idle sessions time out.

### Claude Desktop
- **Claude Desktop for Linux (GA)** — Official Linux desktop client (Ubuntu and Debian) launched June 30 and is now generally available.
- **Cowork expands to mobile & web** — Background work, scheduled tasks, shared chats, and mobile approvals are rolling out to Max-plan users on both mobile and web.
- **Monthly Recap (beta)** — `Settings → Reflect` now shows a monthly summary of topics you spent time on and how you work; in beta for Max users.

### Claude Tag (Slack)
- **Launched August 3, 2026** — Claude Tag is now the official Slack integration on Team and Enterprise plans, replacing the older Claude in Slack app. Anyone in a channel can @-mention Claude, and the whole team sees it work in the thread.

### Models & API
- **Claude Opus 5 released (July 23)** — New top-tier model with 1M-token context and `xhigh` reasoning mode, aimed at the hardest coding and knowledge tasks.
- **Claude Sonnet 5 is now the default model in Claude Code** — Promotional pricing runs through August 31, 2026; standard pricing takes effect September 1.
- **Claude Opus 4.1 deprecated** — API retirement date is August 5, 2026; Anthropic recommends migrating to Claude Opus 4.8.

### MCP Protocol
- **MCP spec 2026-07-28** — Major protocol release: moves from bidirectional stateful connections to a request/response model, enabling MCP servers to run on serverless and edge infrastructure. OAuth 2.0 / OIDC alignment allows enterprise identity systems (Entra, Okta) to connect without workarounds.

## Community Buzz & Interesting Use Cases

- **CodePath education partnership** — Anthropic announced a partnership with CodePath to bring Claude Code into CS programs at community colleges, state schools, and HBCUs. Over 100 students piloted the tool in fall 2025 on open-source projects including GitLab, Puter, and Dokploy — now expanding.
- **Vertex AI deployment webinar** — Anthropic ran a partner-series webinar on deploying Claude Code Skills on Vertex AI, showing enterprise teams how to host Claude Code agents at scale on Google Cloud.
- **Artifact live data via MCP** — Published claude.ai artifacts can now call MCP connectors on each page view, enabling live dashboards instead of static snapshots — getting notable traction with teams building internal tooling.
