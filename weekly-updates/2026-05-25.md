# Claude Weekly Update — May 25, 2026

_Covering: May 18–May 25, 2026_

---

## Shipped This Week

### `/code-review` Replaces `/simplify`
The `/simplify` command has been renamed `/code-review` and overhauled. It now runs a correctness-focused bug review at a configurable effort level (e.g., `/code-review high`) and gains a `--comment` flag that posts findings as inline GitHub PR comments. The old cleanup-and-fix behavior is gone entirely.

### Pinned Background Sessions
`Ctrl+T` in `claude agents` pins a background session so it stays alive when idle, restarts in-place to pick up Claude Code updates, and is only shed under memory pressure after non-pinned sessions. Useful for long-running background workers you can't afford to lose.

### `claude agents --json` and OTEL Tracing
`claude agents` now accepts `--json` for machine-readable output, making it scriptable. Agent metadata (`agent_id`, `parent_agent_id`) is also injected into OTEL spans, giving teams real observability into multi-agent workloads.

### `/usage` Per-Category Breakdown
`/usage` now breaks down consumption by category: skills, subagents, plugins, and per-MCP-server cost. Makes it easier to see what's actually driving your limits.

### Security Fixes (v2.1.149)
A batch of security patches landed covering a PowerShell permission bypass, a sandbox write-allowlist gap in git worktrees, and a permission-analysis hole for `PWD`/`OLDPWD`/`DIRSTACK`. If you're on an older version, update.

### `/diff` Keyboard Navigation
The `/diff` detail view now supports full keyboard scrolling: arrow keys, `j`/`k`, `PgUp`/`PgDn`, `Space`, `Home`/`End`.

### GFM Task List Rendering
Markdown GFM task list checkboxes now render properly in Claude Code output.

### Enterprise: `allowAllClaudeAiMcps` Managed Setting
Admins can now push a managed setting to allow all claude.ai MCP servers org-wide without per-user prompts.

### Self-Hosted Sandboxes (Public Beta) & MCP Tunnels (Research Preview)
Announced at Code with Claude London on May 19. **Self-hosted sandboxes** let tool execution run on infrastructure you control — your own servers or managed providers (Cloudflare, Daytona, Modal, Vercel) — while Anthropic handles the agent loop. **MCP tunnels** let Managed Agents reach MCP servers inside private networks without opening inbound firewall rules or exposing public endpoints; a lightweight gateway makes one outbound encrypted connection.

### KPMG Global Alliance
KPMG signed a global strategic alliance with Anthropic, embedding Claude into **Digital Gateway** — the platform its 276,000+ employees and clients use for the actual delivery work. Initial focus is tax and legal; private equity is next, with full Azure deployment targeted for September 2026. KPMG is also named Anthropic's preferred partner for private equity.

## Community Buzz

**Code with Claude London** ran May 19–21 — Anthropic's first developer conference outside the US. The opening keynote quote getting the most play online: Boris Cherny (Head of Claude Code) said "The default isn't 'I'm going to prompt Claude' — the default is now 'I'm going to have Claude prompt itself'." MIT Technology Review covered the event with a notably mixed take, noting that the future of coding being shown off was impressive but also unsettling to many developers in the room.

**Dreaming** generated significant discussion this week. The idea that agents can now consolidate their own memory between sessions — essentially improving themselves without a human in the loop — struck many developers as a conceptual step change, not just a feature. Several threads on X and Hacker News debated whether this is closer to fine-tuning or to long-term memory, with Anthropic engineers clarifying it's strictly a read/write operation on a memory store, not weight updates.

**`/code-review` rollout** is getting traction as a practical workflow: developers are running `/code-review high --comment` as a pre-merge step and reporting it catches real bugs (not just style issues) that reviewers miss. A few teams are wiring it into their CI via routines so it fires automatically on every PR.

**KPMG × Anthropic** coverage dominated the enterprise AI beat this week. The scale — 276,000 people, Big Four, embedded into the actual client delivery software rather than bolted on as a chatbot — is being held up as the model for what real enterprise AI adoption looks like vs. "pilot theater."
