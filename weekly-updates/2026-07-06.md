# Claude Desktop & Claude Code Weekly Update
**Week of June 30–July 6, 2026**

---

## New Features & Changes Shipped

### Claude Sonnet 5 — New Default Model (June 30)
Anthropic shipped Claude Sonnet 5, the most agentic Sonnet tier model to date, and made it the default for Free and Pro plans.
- **Agentic coding:** Scores 63.2% on agentic coding benchmarks — up from Sonnet 4.6's 58.1%, approaching Opus 4.8's 69.2%.
- **1M token context window by default:** No smaller context variant; 128k max output tokens.
- **Adaptive thinking** and full tool/platform feature parity with prior Sonnet models.
- **Cybersecurity safeguards:** First Sonnet-tier model with real-time blocking of prohibited or high-risk cybersecurity requests.
- **Introductory pricing:** $2/$10 per million input/output tokens through August 31, 2026; available on all plans.

---

### Claude Fable 5 & Mythos 5 Restored (July 1)
After a 19-day suspension triggered by a US government export-control directive (issued June 12, lifted June 30), both models came back online globally.
- The suspension followed documented research showing a method to bypass Fable 5's safety controls to extract vulnerability exploitation code.
- Anthropic patched the vulnerability with an updated automated classifier before redeploying.
- Both models are now available across Claude.ai, Claude Platform, Claude Code, Claude Cowork, AWS, and Microsoft Foundry.

---

### Claude Code Reliability & UX Improvements
- **Manual default permission mode:** New default that requires explicit approval for each new class of action rather than auto-granting at session start.
- **Smarter AskUserQuestion behavior:** Background agents route prompts to the main session instead of blocking or auto-denying.
- **Artifacts:** Session work can now be turned into live, shareable web pages (PR walkthroughs, incident pages, dashboards, checklists). Private org-only sharing and version history in beta for Team and Enterprise.
- **Readable session names:** Sessions now get readable default names at start — easier to identify and message.
- **Clickable file attachments:** Cmd/Ctrl-click a chat file attachment to reveal it in Finder or Explorer.
- **Organization default models:** Admins set a default model in the org console; it surfaces as "Org default" (or "Role default") in `/model` when users haven't overridden it.
- **Memory-pressure reaping:** Automatic cleanup of idle background shell commands under memory pressure.
- **Crash, session, plugin, accessibility, voice dictation, and terminal rendering fixes** across CLI and background agent paths.

---

### Claude Desktop & Claude Cowork
- **Claude Cowork GA:** Now generally available on macOS and Windows via Claude Desktop. Enables parallel background agents alongside main sessions.
- **Official Linux Desktop:** Anthropic shipped a first-party Claude Desktop for Linux, ending reliance on community ports.
- **Unified Customize panel:** A new Customize section in Claude Desktop groups skills, plugins, and connectors in one place.

---

### Claude Design Updates
- Sticks to your design system across projects; added direct on-canvas editing.
- Tighter integration with Claude Code (design-to-code workflows).
- Now lives in the sidebar of the Claude Desktop app.
- Over **one million users** in its first week since launch.

---

### Enterprise & Admin
- **Richer admin analytics:** Deeper visibility into usage, cost, and productivity trends per user and team.
- **Model-level entitlements & spend alerts:** Admins can set per-model access rules and receive cost threshold alerts.
- **User groups:** Organize users manually or via SCIM from your identity provider; assign each group a custom role defining which Claude capabilities its members can use.
- **Claude Apps Gateway:** New self-hosted control plane for Amazon Bedrock and Google Cloud deployments — corporate SSO, centrally enforced policy, role-based access, and per-user cost attribution for Claude Code.
- **Rate limits increased** across Chat, Cowork, Claude Code, and Claude Platform to accommodate higher token usage at higher effort levels.

- **Fable 5 pricing for consumer plans:** Availability and pricing for Fable 5 on Free/Pro tiers has not been confirmed; currently only accessible via API and Max/Team/Enterprise.

## Community Buzz & Interesting Use Cases

- **Fable 5 outage lessons:** The 19-day suspension prompted a wave of enterprise write-ups on AI-as-infrastructure risk. The consensus: organizations that had treated frontier models as critical dependencies were caught flat-footed; expect more multi-model fallback architectures going forward.
- **Viral branded video pipeline:** A developer used Claude Code to orchestrate an end-to-end video production workflow — scripting, ElevenLabs voiceover, Google Veo 3 visuals, background music, and ffmpeg stitching — producing an export-ready MP4. 5,000+ likes on X.
- **Gesture-controlled 3D interface:** A Three.js + MediaPipe project where webcam hand gestures drive a physics particle engine, built entirely through Claude Code prompting.
- **Total War: Three Kingdoms AI coach:** Claude Code connected to a running game session via MCP + screenshot analysis, delivering live strategic advice by synthesized voice during battles.
- **Claude Design's first-week traction:** 1M users is notable velocity; community chatter is particularly active around design-to-code handoffs with Claude Code, reducing the designer-to-developer round-trip significantly.
- **Sonnet 5 as agentic infrastructure:** TechRadar and TechCrunch both framed the Sonnet 5 launch as a signal that the "AI war is shifting from chat to agents" — Sonnet 5's price point makes running many parallel agents economical in a way previous tiers weren't.
