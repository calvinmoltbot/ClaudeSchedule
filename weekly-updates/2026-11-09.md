# Claude Desktop & Claude Code Weekly Update
**Week of November 2 – November 9, 2026**

---

## New Features Shipped

### Claude Desktop / Claude App

- **Unified Claude default (rolling out Nov 10):** Starting at 12:00 PM PT on November 10, 2026, Claude Desktop will open with Cowork enabled by default — even on devices where `coworkTabEnabled` is false and no explicit `desktopHome` setting exists. Admins should note that session retention is now governed by `coworkSessionRetentionDays`, not `chatSessionRetentionDays`; set both to avoid unexpected retention-policy gaps.
- **Admin controls (beta):** Admins can now manage the most common Claude Desktop settings without requiring a device management push (MDM). Available to Team and Enterprise plan admins.
- **Endpoint detection & response in Cowork (beta):** EDR integration is now in beta on macOS and Windows for Claude Team and Enterprise, enabling security teams to monitor Cowork activity alongside other endpoint telemetry.
- **Monthly Reflect recap (beta):** Available under Settings → Reflect, this monthly overview shows usage topics and patterns. Requires Memory to be enabled.

### Claude Code CLI (v2.1.317–2.1.319)

- **Email confirmation prompt before web/shell tool calls:** Claude Code now shows a confirmation prompt before any web or shell tool sends your account email address to an external service. This change was listed in the official changelog on November 3–6, 2026.
- **`onFailure: "block"` for Agent SDK hook callbacks:** Agent SDK hook callbacks can now set `onFailure: "block"` to block the agent from proceeding when a hook fails, giving hook authors more control over failure modes.
- **Sign-in expiry visible in CLI:** `claude auth status` and `claude -p` output now display your session's sign-in expiry timestamp (v2.1.318, Nov 3, 2026).
- **`permissions.blockWritesOutsideWorkingDirectories`:** A new config option that prevents Claude Code from writing files outside the working directory tree. Useful for sandboxed or shared environments (v2.1.314).
- **Auto mode no longer falls back to built-in classifier:** Auto mode permission decisions that cannot be verified server-side now result in a prompt or denial rather than a silent local-classifier fallback.
- **IDE extension installation change:** Claude Code no longer auto-installs or auto-updates the IDE extension when launched from an IDE terminal. Existing installs are unaffected; new installs require a manual step.

## Announced but Not Yet Released

- **Opus 4.8 Fast Mode removal (Nov 30):** Fast mode for Opus 4.8 is deprecated and will be fully removed on **November 30, 2026**. After that date, fast-mode requests targeting Opus 4.8 will return an error. Migrate to **Opus 5.5** to retain fast-mode capability.
- **Claude Duet:** Still in research preview / waitlist for US Pro and Max subscribers. No general availability date announced yet.
- **Claude Security continuous scanning (Enterprise beta):** Continuous code scanning with fix tracking remains in public beta for Enterprise. GA timeline not announced.

## Community Buzz & Interesting Use Cases

- **DEV Community weekly roundup:** The "This week in Claude Code" series (week of Nov 8) highlighted the auto mode classifier change as the most impactful behavioral shift of the week, noting that some users are seeing more prompts but feeling better about authorization clarity.
- **Admin-managed settings enthusiasm:** Enterprise admins are sharing relief that the new admin controls remove the need to push MDM profiles just to standardize Cowork settings — a common friction point since Cowork went GA.
- **`blockWritesOutsideWorkingDirectories` for CI:** Teams are adding this flag to CI/CD environments to prevent Claude Code agents from accidentally writing outside the repo during automated runs.
- **Hook-based guardrails:** The `onFailure: "block"` addition is seeing early use in compliance-heavy teams building hooks that verify outputs against policy rules before allowing agent actions to proceed.
- **Mars rover story resurfacing:** Anthropic's mention that Claude helped NASA's Perseverance rover navigate 400 meters on Mars continued to circulate widely in AI communities this week.
- **Agent Teams adoption:** Third-party platforms adopting Claude's Agent Skills have reportedly surpassed 70, including Cursor, GitHub Copilot, and VS Code — driving discussion about standardized agent interop patterns.
