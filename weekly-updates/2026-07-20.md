# Claude Weekly Update — July 20, 2026

> Covering Claude Desktop, Claude Code, and Anthropic announcements from the past 7 days.

---

## Shipped This Week

### Memory: Individual Entries Replace Daily Summary
Claude's memory system has been rebuilt from the ground up. Instead of a rolling daily summary, memory now works as a set of individual, categorized entries that Claude reads and updates during conversations. The result is finer-grained recall — Claude remembers specific preferences, recurring topics, and project context separately rather than folding them into one paragraph. Requires Memory to be on in settings.

### Artifacts: Live MCP Connector Data
Published Artifacts can now call MCP connectors at view time, not just at build time. A dashboard Artifact shows live data every time someone opens it — not a snapshot frozen when the session ran. Actions (write operations through connectors) can also be triggered from an Artifact page, making them lightweight interactive tools, not static reports.

### Claude Code: Screen Reader Mode
A new accessibility mode replaces the visual terminal UI with plain, linear text that screen readers like VoiceOver and NVDA can navigate in order. Three ways to enable it: `--screen-reader` flag per session, `CLAUDE_AX_SCREEN_READER=1` environment variable per shell, or `axScreenReader: true` in settings for all sessions.

### Claude Code: `/fork` and `/subtask` Commands Reworked
`/fork` now copies the current conversation into a new *background* session with its own row in `claude agents`, leaving the current session untouched. The old in-session subagent that `/fork` used to launch is now `/subtask`. If you relied on `/fork` for inline sub-work, update your workflow to `/subtask`.

### Claude Code: Broad Stability and Safety Update
A significant stability pass shipped this week: tighter permission checks, safer Bash and PowerShell execution, improved cleanup of background sessions, stronger telemetry, and better reliability for remote sessions and plugins. New additions include the `EndConversation` tool (for cleanly terminating agent sessions programmatically) and progress heartbeats for long-running tasks.

### Plugin Marketplace and Admin Controls
A curated plugin marketplace is now live for Team and Enterprise plans. Admins can browse and enable plugins org-wide, and the new admin controls allow organizing users into groups and assigning each group a custom role — defining which Claude capabilities, Cowork features, and plugins members can access. Department-level configuration is now practical.

### Claude for Government (Beta)
Claude for Government launched in beta. It targets US federal, state, and local agencies with data-handling standards and controls tailored for government use. Organizations can request access at claude.ai/solutions/government.

### HIPAA Self-Serve Configuration
Enterprise and API organizations with a BAA in place can now enable HIPAA-compliant mode themselves from the admin console — no support ticket required. Includes a guide download, one-step enablement, and BAA review status tracking.

### Claude for Teachers
Anthropic launched Claude for Teachers, giving verified US K-12 educators free access to premium Claude features, lesson-planning tools, and curriculum connections aligned to state standards across all 50 states. New education-specific MCP connectors are included.

### Developer Platform: Managed Agents Expansion
The Managed Agents API gained several new capabilities: event delta streaming, backward pagination over session history, session-level model and capability overrides, vault injection controls for secrets, and broader webhook events. Teams building agentic pipelines on the API have substantially more control over long-running sessions.

### Developer Platform: API Key Expiration
API keys and Admin API keys can now have an expiration date set at creation time. Expiring keys trigger email reminders to the key owner and appear in admin reporting, making rotation workflows and compliance audits easier to manage.

## Announced but Not Yet Fully Rolled Out

- **Cowork on mobile/web** — rollout is ongoing; Max plan first, broader access still coming over the next weeks.
- **Dynamic Workflows** — Enterprise/Team/Max research preview for spawning hundreds of parallel sub-agents; not generally available.
- **Claude Science** — the AI workbench for computational biology and drug discovery announced late June; access is still limited/invite-only.
- **Artifacts org-wide sharing and version history** — currently Team and Enterprise beta only; broader access not yet dated.

## Community Buzz

**Fable 5 + the `/goal` loop** is generating enthusiastic write-ups. With Fable 5 restored after its brief export-control suspension, developers are combining it with long-running `/goal` sessions to tackle open-ended tasks (refactoring entire modules, research pipelines) that don't fit a fixed prompt. Several tutorials this week show six- and seven-step "insane projects" — though the community is also noting the token cost adds up fast.

**Live Artifact dashboards** triggered immediate experimentation after the MCP connector update. Early posts show teams replacing internal status pages and Notion dashboards with Artifacts that pull live GitHub, Jira, and Slack data through connectors — no backend hosting required.

**n8n + Claude Code orchestration** is a recurring startup pattern this week: n8n handles routing and triggering, Claude handles judgment calls. Teams are using this to automate lead qualification, personalized outreach drafts, and edge-case flagging without writing custom orchestration code.

**Claude for Teachers** drew notable reaction on X/Twitter among edtech circles. The main conversation is less about the feature itself and more about whether free premium access to teachers will meaningfully shape how the next cohort of students is introduced to AI.
