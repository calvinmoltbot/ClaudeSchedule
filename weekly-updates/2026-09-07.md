# Claude Weekly Update — September 7, 2026

> Covering Claude Desktop and Claude Code updates from the past 7 days (2026-09-01 to 2026-09-07).

---

## Claude Code — Shipped

### v2.1.257 — Fable 5.1 Default + Security Hardening (September 1)
The week's biggest Claude Code release landed on September 1, bringing several notable changes:
- **Claude Fable 5.1 set as the default Fable model** — 1M context window, $10/$50 per million tokens input/output, $0.25/Mtok cache reads (a 75% cache-read price cut)
- **Containment Escape rule for auto mode** — cloud metadata-credential fetches, egress evasion attempts, and cross-tenant requests are no longer auto-approved unless the environment explicitly marks them expected. A meaningful security hardening for agentic sessions
- **New timeFormat / timeZone settings** — supports 12-hour, 24-hour, 24-hour UTC, or a custom strftime pattern for the turn-end clock and transcript timestamps

### v2.1.258 — Mac Crash Fix (September 1)
A same-day follow-up release fixing critical issues that prevented Claude Code from launching on older Mac systems and resolved remote session failures.

### v2.1.259 — managedMcpServers Setting (September 2)
Added `managedMcpServers` as a managed setting, allowing organizations to push MCP server configuration centrally.

### v2.1.260 — Side-by-Side Diff Panel (September 3)
Uncommitted changes now appear in a **live side-by-side diff panel** as edits happen. Reviewers no longer have to run `git diff` manually to see what Claude has changed — it surfaces in the UI in real time.

### v2.1.261 — /skill-doctor, Output Limits & Policy Diagnostics (September 4)
A feature-rich release:
- **`/skill-doctor`** — new slash command that shows which loaded skills go unused and what each costs in context tokens. Useful for trimming bloated skill configs
- **`bashOutputMaxChars` and `taskOutputMaxChars` settings** — raises the inline output limit before content is saved to a file, up to 128K characters. Long build logs and test output no longer get truncated prematurely
- **`--append-subagent-system-prompt-file`** flag — reads the subagent system prompt from a file, for prompts too long to pass on the command line
- **Organization policy diagnostics** — `/status` and `claude doctor` now show an "Organization policy" line explaining why a policy couldn't be loaded (e.g., a proxy blocking the endpoint)
- **Bug fixes**: characters landing out of order during fast input or key repeat; `/add-dir <subdirectory>` incorrectly printing a "couldn't be resolved" error on `/net` automounts

### v2.1.262 — Bug Fixes (September 6)
Reliability and bug-fix release. Specific details not yet in public changelogs.

### Binary Size Reduction
Separately noted this week: the Claude Code binary is now **zstd-compressed — about 75 MB instead of 340 MB on Linux x64**. Significant improvement for installs and auto-updates.

## Claude Desktop & Platform — Shipped

### Claude Fable 5.1 and Claude Mythos 5.1 Launch (September 1)
Anthropic officially launched two new models:
- **Claude Fable 5.1** — generally available on the Claude API, AWS, GCP, and Azure. Keeps Fable 5 pricing on input/output but cuts cache-read pricing by 75%. Three compatibility-breaking changes from Fable 5 that existing integrations should test before migrating
- **Claude Mythos 5.1** — the same underlying model with lighter safeguards, restricted to vetted organizations through trusted-access programs. Not publicly selectable

### Claudeforce — Salesforce × Anthropic Partnership
Salesforce and Anthropic announced **Claudeforce** — an expanded strategic partnership embedding Claude across Salesforce's CRM, workflows, and governance stack. Available to select pilot customers now; open beta targeting September 2026.

### Cowork on Web & Mobile (Expanded)
Claude Cowork now runs across web and mobile in addition to desktop. Remote sessions (in beta) save files and session state to a Claude account, sync across devices, and **continue running scheduled tasks server-side when the laptop is closed**.

### Claude Developer Platform Additions
- Budget controls for Managed Agents sessions
- Advisor support
- Geo-pinned inference
- GitHub-loaded skills for Managed Agents

### Education: K-12 Academy & Detroit Pilot
Anthropic updated Claude for K-12 Academy with free AI fluency content (courses, guides, classroom workflows). A pilot of Claude for Teachers is launching in Detroit Public Schools this fall.

## Community Buzz

- **Fable 5.1 reactions are split.** API users are enthusiastic: 800K+ token contexts surviving without compaction, 75% cache-read savings, and the ability to run overnight ticket batches unattended. Max subscription users are frustrated: multiple 20x Max plan holders report hitting five-hour session limits for the first time, with some estimating effective weekly Fable allowance dropped from ~$1,250 to ~$875 of list value
- **`/skill-doctor` is generating immediate interest** — developers are discovering their skill configs are heavier than expected and are trimming unused entries to free up context
- **The side-by-side diff panel** (v2.1.260) is being praised as a long-requested quality-of-life improvement for reviewing agentic edits
- **The 75 MB binary** (down from 340 MB) is drawing positive attention in developer threads — auto-update times are noticeably faster
- **Containment Escape rule** is getting attention from security-conscious teams running autonomous agents in cloud environments; the opt-out-or-whitelist model is seen as the right default
