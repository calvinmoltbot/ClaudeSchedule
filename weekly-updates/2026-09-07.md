# Claude Weekly Update — September 7, 2026

> Covering Claude Desktop and Claude Code updates from the past 7 days (2026-09-01 to 2026-09-07).

## Claude Code — Shipped

### v2.1.252 — Bug Fixes (August 31)
- Fixed Bash commands failing with "task output swap refused" on some Macs
- Fixed "always allow" not saving in projects with no `.claude/settings.local.json`
- Fixed Remote Control sessions stalling after a tool finished when the claude.ai connection was degraded
- Fixed large background task failure output exceeding the API request size limit

### v2.1.257 — Fable 5.1 Default + Time Format Settings (September 1)
- **Claude Fable 5.1 set as the default model** — the `fable` alias now resolves to Fable 5.1 (1M context, $10/$50/MTok, $0.25/MTok cache reads)
- New customizable `timeFormat` and `timeZone` settings: 12-hour, 24-hour, 24-hour UTC, or a custom strftime pattern for turn-end clock and transcript timestamps
- Fixed command-line and session rules being dropped on the first settings reload

### v2.1.259 — Managed MCP Servers (September 2)
Added `managedMcpServers` to the managed settings layer, enabling org admins to centrally deploy and configure MCP servers for all sessions in their organization.

### v2.1.260 — Diff Panel, Cache Diagnostics, and Dozens of Fixes (September 3)
The week's largest release:

**New features:**
- **Diff panel** — opens beside the conversation in fullscreen mode, showing all uncommitted changes as Claude edits; toggle with `/diff`
- Added **likely cause for prompt-cache misses** (e.g. "tool definitions changed", "idle past TTL") to `/cost` and the status line — useful for debugging why cache isn't hitting
- Added `/advisor` text form for desktop, Remote Control, and headless sessions
- Added `oidc.scope_on_refresh` to the Claude apps gateway for IdP compatibility

**Security fix:**
- Fixed `Edit`/`Write`/`Read` permission rules with parentheses in path being silently dropped, which left "read-only" folders writable — a meaningful security regression now corrected

**Bug fixes (selection):**
- Fixed prompt caching on Fable 5.1 not covering context after tool results
- Fixed the `/model` picker not showing Fable 5.1 for eligible orgs
- Fixed Bedrock model discovery failing behind TLS-inspecting proxies
- Fixed many Remote Control issues: stale permission mode, stuck spinner after stop, `SendMessage` to offline session appearing delivered, phantom session in `ListAgents`
- Fixed `/rewind` leaving stale file-read tracking and reporting success when backup files were missing
- Fixed subagent completion notifications going to the main conversation instead of the waiting parent
- Fixed Artifact tool failing on first call in some Cowork sessions
- Fixed IDE line selections being dropped when running a skill/slash command
- **Removed the one-hour time limit on background commands started by subagents**

**VS Code additions:**
- "Build a custom style" walkthrough in the Output styles menu
- Add/Remove MCP server form inside the IDE (no more leaving VS Code to configure MCP)
- Hollow ring in session list for sessions open in another window or terminal
- Fold button on permission/question prompts so you can read the conversation behind them

### v2.1.261 — /skill-doctor, Output Limits, Policy Diagnostics (September 4)
**New commands and settings:**
- **`/skill-doctor`** — shows which loaded skills go unused and what each costs in context tokens; prune configs that are heavier than you realized
- **`bashOutputMaxChars` and `taskOutputMaxChars`** — raises the inline output limit before content is saved to a file, up to 128K characters; long build logs no longer truncate prematurely
- **`--append-subagent-system-prompt-file`** — load subagent system prompts from a file for very large prompts
- Added "Organization policy" line to `/status` and `claude doctor` explaining why a policy couldn't load (e.g., a proxy blocking the endpoint)
- Improved `/model` picker and VS Code model pill to show friendly names instead of raw Bedrock/Vertex IDs
- Improved Vertex AI startup: no longer re-runs GCP project discovery or spawns extra `gcloud` processes
- Improved `rm -rf` safety prompt to catch more patterns (positional parameters, double-quoted `sh -c` scripts)
- Changed `Ctrl+W / Alt+F / Alt+D` word-editing keys to match Bash behavior
- Changed auto mode to treat diagram-renderer URL links as site uploads (no longer auto-approved)
- Changed `/context` token counting to use local estimates when the token-count API is unavailable

### v2.1.263 — Bug Fixes (September 6)
Reliability and bug-fix release; specific details not published in public release notes.

### Binary Size Reduction
Noted separately this week: the Claude Code binary is now **zstd-compressed — ~75 MB instead of 340 MB on Linux x64**. Auto-update times are noticeably faster.

## Claude Desktop & Platform — Shipped

### Fable 5.1 and Mythos 5.1 Launch (September 1)
Anthropic launched two new models:
- **Claude Fable 5.1** — generally available on Claude API, AWS, GCP, and Azure. 1M context, 128K max output, always-on adaptive thinking. Base pricing unchanged from Fable 5; **cache-read pricing cut 75%** (from $1.00 to $0.25/MTok). Anthropic estimates ~25% savings on typical workloads, up to 45% on heavy agentic ones. Three compatibility-breaking changes from Fable 5 — test integrations before migrating
- **Claude Mythos 5.1** — same underlying model with lighter safeguards, restricted to vetted organizations via trusted-access programs. Not publicly selectable

### Background Computer Use on Mac (September 2)  ⭐ Major Feature
Anthropic upgraded computer use so Claude can operate apps **in background windows while you keep working in the foreground**. Claude clicks, types, and opens apps without seizing your mouse or keyboard, pausing if you begin typing. Requirements: macOS 15+; available on Pro and Max plans. In Cowork, priority order is: native connectors (Gmail, Drive, M365, Slack) → built-in browser → direct screen interaction as a fallback.

### Built-in Browser in Claude Cowork (Desktop)
Claude Cowork on the desktop app gained a **built-in browser side panel**. Claude opens websites inside the panel, navigates, reads, clicks, and types — entirely separate from your own browser. You can bring logins over from Chrome/Edge/Firefox (macOS) or Firefox (Windows/Linux). Rolling out to Pro, Max, Team, and Enterprise.

### Claude Cowork in Chrome Side Panel
A separate launch brought Claude Cowork to the **Chrome browser side panel**, letting you invoke Claude directly alongside any webpage.

### Cowork on Web & Mobile — Remote Sessions (Beta)
Cowork sessions now run server-side: files and state are saved to your Claude account, synced across devices, and **work continues after you close your laptop**. Scheduled tasks run on Anthropic's schedule server — no device needs to stay on.

### Enterprise Frontier Safeguards (EFS) (September 1)
Anthropic launched EFS, combining zero-data-retention privacy with safety monitoring. Data is stored in cloud infrastructure controlled by the customer, not Anthropic. Aimed at enterprises needing both strict privacy and compliance.

### Claude Developer Platform — `ant apply` (v1.30.0)
The `ant` CLI gained `ant apply`, enabling infrastructure-as-code management of agents, environments, skills, memory stores, and deployments from repository files.

### Claudeforce — Salesforce Partnership (Open Beta Coming)
Salesforce and Anthropic announced **Claudeforce** (August 26), bringing Claude into Salesforce's CRM, workflows, and governance stack. Pilot customers are live now; open beta expected September 2026.

### Claude for Teachers — School & District Expansion
Originally launched July 14 for individual U.S. K-12 educators, Claude for Teachers expanded to **school and district organizations** (announced August 28). Schools signing up by June 30, 2027 get a full year of free Enterprise access. Free AI fluency content (courses, guides, classroom workflows) added to K-12 Academy this week. A pilot is launching in Detroit Public Schools.

## Security Notice

### Malicious `.git/config` Pre-Trust Execution (CVE-2026-55607, September 2026)
Hacker News surfaced research showing that malicious `.git/config` files can make Claude Code — and other AI coding agents — run attacker code **before workspace-trust prompts are accepted**, by exploiting `git fsmonitor` execution during worktree operations. This is related to a Claude Code security advisory first issued in June 2026; a new write-up in September escalated community discussion about pre-trust execution risks across AI coding agents broadly. Worth reviewing if you routinely open unfamiliar repositories.
